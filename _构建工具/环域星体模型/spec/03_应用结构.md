## 〇、一句话与总图

**一句话**：一个页面、一块画布、两种视图（神的视角“总览”、生活其中的人的“第一人称”），共用同一个时间、同一个地点、同一份参数；右侧是图表与读数，底部是时间栏。所有数从 `HY.astro` 来，所有状态在 `HY.store` 里，所有画面经 `HY.gfx` 这一个渲染器出图。

```
              ┌──────────────── HY.store：HY.state ＋ 事件总线 HY.bus ────────────────┐
  ui/*  ──写──▶│ time · site · view · ov · fp · astro · zones · ui                      │──事件──▶ 各模块
              └──────────────┬──────────────────────────────────────────────────────────┘
                             ▼
       HY.model（P、当前地点、此刻快照、缓存）──调用──▶ HY.calc（纯函数：表、搜索）──▶ HY.astro
                             │
  HY.app（启动、帧循环、视图切换、测试接口）
       ├── HY.gfx（唯一的 THREE.WebGLRenderer 与 <canvas id="gl">）
       │     ├── HY.ov  总览三维（three 场景、螺旋、塔影、分域、地点、标签）
       │     └── HY.fp  第一人称（02 的全屏 pass 管线）
       ├── HY.charts  二维图表（天空、一日、一年、日月高度、子午线、本月月相）
       └── HY.ui      布局、时间栏、地点卡、读数、参数、说明、第一人称 HUD、快捷键
```

**数据流只有一个方向**：界面与输入只写 `HY.store`；`HY.store` 发事件；视图、图表、读数听事件、读 `HY.model`，自己不改别人的状态。唯一的例外是第一人称步行：`HY.fp` 把步行后的位置以 `src: 'walk'` 写回 `site`（第七节第 8 条）。

## 二、通用约定

### 1. 经典脚本与命名空间

全部是经典脚本，不用 ES module，不跨文件 import。每个文件是一个立即执行函数，挂在全局 `HY` 下；**只往命名空间上加属性，不重新赋值命名空间对象**（子模块先加载、入口后加载，入口不能把子模块冲掉）：

```js
(function (G) {
  'use strict';
  var HY = G.HY = G.HY || {};
  var ns = HY.ov = HY.ov || {};          // 只加属性
  ns.geom = { helix: helix, trail: trail /* … */ };
  function helix(P, body, turns) { /* … */ }
})(typeof globalThis !== 'undefined' ? globalThis : window);
```

- **加载时不碰 DOM、不碰 THREE**。DOM 与 THREE 只在 `init()` 里用。这样节点可测模块能在 node 里直接加载，THREE 没加载上（离线双击）时其余模块也不崩。
- 节点可测模块不得引用 `window`、`document`、`localStorage`、`THREE`；要存储就走 `HY.util.storage`，它在 node 里退回内存。
- `src/astro.js` 保持现有的 UMD 写法（`module.exports` 与 `root.HY.astro` 两挂）。

### 2. 单位与精度

- 长度 km，时间“日”（`t` 与 01 相同：t＝0 是 10018 年十一月初一 0 时、伊美忒地方时），对外角度用度、内部用弧度。
- 总览三维里 **1 个场景单位＝1000 km**（与 v2 相同）。只有 `HY.ov` 内部用场景单位，接口一律 km。
- CPU 一律双精度；进 GPU 前按 02 第三节转 CM 系、`Math.fround`。

### 3. 文案

界面全中文；正文性的说明用中文引号“”；数字用 `IBM Plex Mono` 等宽、`tabular-nums`；大数用千分位（`6,670 公里`）；方位写“南偏西 8°”；时刻同时给钟点与时辰（`21:00 · 亥时初`）。凡是“设定、非物理”的开关，标签后一律加灰色小字“设定”。凡是“示意、非实比例”的画法，画面角落写明放大了什么。

### 4. 出错与降级

- `HY.app` 用 try/catch 包住每个模块的 `init`。失败的模块发 `error` 事件，界面在对应位置显示一句中文说明，其余照常。
- THREE 没加载上：三维区显示“三维视图需要联网加载 three.js（cdnjs）。图表、读数、参数照常可用。”；第一人称按钮置灰。
- 有 WebGL2、无 `EXT_color_buffer_float`：总览照常，第一人称按 02 第十六节第 1 条走 RGBM 降级并强制低档。
- 无 WebGL2：总览用 WebGL1（无 MSAA、直接出图），第一人称置灰并说明原因。
- 运行时不 fetch 任何资源，不起 Worker，不用 `eval`、`document.write`。

### 5. 性能纪律

帧内热路径不分配对象（向量、数组复用）；重计算（年表、子午线、月表、远壁亮暗图）按第四节第 3 条的缓存与节流；图表只在可见时画；`HY.bus` 的 `time` 事件每帧至多一次。

## 三、共享状态与事件（`core/store.js`）

### 1. 接口

```js
HY.state                                // 唯一的状态树（只读约定：除 HY.store 外谁也不直接改）
HY.store.SCHEMA                         // { 'fp.atmo.HR': {def:40, type:'num', min:4, max:80, step:1, persist:true}, … }
HY.store.get(path)                      // 'site.s' → 6670；无参数返回 HY.state
HY.store.set(path, value, src)          // 校验、夹取、写入；值没变不发事件；返回写入后的值
HY.store.patch(path, obj, src)          // 一次写多个字段（如 'site' ← {id, s, az}），只发一次事件
HY.store.reset(scope, src)              // scope 省略＝全部；可为 'astro' | 'zones' | 'ov' | 'fp' | 'fp.atmo' 等前缀
HY.store.load()                         // 启动时从 localStorage 读，坏数据整体丢弃
HY.store.save()                         // 防抖 400 ms；flush() 立即写（页面 pagehide 时调用）
HY.bus.on(evt, fn) → off()              // 订阅，返回取消函数
HY.bus.once(evt, fn)
HY.bus.emit(evt, payload)               // 同步分发；单个监听器抛错只记日志，不影响其它监听器
```

`src` 取值：`'ui'`（界面操作）、`'play'`（播放推进）、`'jump'`（跳转）、`'walk'`（第一人称步行）、`'ov'`（总览里点选）、`'api'`（测试接口）、`'load'`、`'reset'`。监听者靠 `src` 避免回环（例如第一人称收到 `src: 'walk'` 的 `site` 事件不瞬移）。

### 2. 事件

`set`／`patch`／`reset` 以**顶层键**为事件名发出，载荷 `{path, value, prev, src}`。另有系统事件：

| 事件 | 发出者 | 载荷 | 典型监听者 |
|---|---|---|---|
| `time` | store | `{path:'time.t', value, prev, src}`；播放时每帧至多一次 | 视图、图表（节流）、读数、时间栏 |
| `site` | store | 新地点 | 视图、图表、读数、地点卡 |
| `view` | store | `{value:'ov'|'fp', prev}` | app（切视图）、布局 |
| `ov`、`fp`、`astro`、`zones`、`ui` | store | 变化的路径与值 | 对应模块 |
| `model` | model | `{what:'P'|'site', pv}`：P 或地点对象已重建 | 图表、视图、读数 |
| `frame` | app | `{t, dtReal, dtSim, now}` | HUD、标签、图表游标 |
| `layout` | ui/layout | `{w, h, mobile, panel}` | gfx、图表 |
| `ready` | app | `{part:'ov'|'fp'|'charts'|'ui'}` | 测试、提示 |
| `progress` | fp | `{phase, done, total, label}` | HUD 的“正在准备”条 |
| `quality` | fp | `{tier, reason}` | HUD、参数面板 |
| `error` | 任何 | `{part, message}` | 布局（显示降级说明） |
| `context` | gfx | `{lost:boolean}` | 视图（重建 GPU 资源） |

### 4. 校验与持久化

- 每条 `SCHEMA` 带 `def`、`type`（`num|bool|enum|str|obj`）、`min`/`max`/`step` 或 `opts`。`set` 先夹取再写；枚举不在 `opts` 里就丢弃并在控制台警告。
- 跨字段约束在 store 里做：`zones.gHeavy ≥ zones.gLight + 0.02`；`astro.o.rM > a + 50`；`astro.o.dS ≥ a + rhoS + 5`。违反时夹到边界并发 `error`（界面在参数页显示一行黄字）。
- 本地存储键 `huanyu-xingti-v3`，内容 `{v:3, state:{…只含 persist 字段}}`。读到 `v` 不符或解析失败，整体丢弃、用默认。v2 的键 `huanyu-xingti-v2` 不迁移（参数体系不同）。所有读写包在 try/catch 里，隐私窗口或存储被禁时静默退回内存。
- 恢复默认：参数页底部“恢复默认”（全部，保留 `view.mode` 与 `ui.*`）；每个参数组标题右侧有“本组默认”。

### 1. 唯一的渲染器

| 项 | 值 | 理由 |
|---|---|---|

| `toneMapping` | `NoToneMapping` | 同上；两种视图各自在最后一个 pass 里做色调映射与 sRGB |
| `autoClear` | false | 第一人称要求；总览自己 `clear()` |
| `setPixelRatio` | 1 | 尺寸由 `gfx.resize` 手算 |
| `localClippingEnabled`、`shadowMap.enabled` | false | 总览的剖切在着色器里做，不用 three 的裁剪面与阴影 |
| `debug.checkShaderErrors` | 开发构建真、发布构建假 | 02 第十六节第 1 条 |
| `logarithmicDepthBuffer` | false | 02 第三节第 5 条 |

`dprCap`：总览 2；第一人称按档位（低 1、中 1.5、高 2；第一人称的内部渲染比例另由动态分辨率管，见 02 第十五节）。

```js

```

```
app 收到 view 事件：
```

## 六、总览三维视图（`HY.ov`）

总览是“神的视角”的示意图，要把三件事一眼讲清：**日月镜像双螺旋**、**塔影就是夜**、**按重力分域与各地的位置**。它允许示意（放大、压缩圈数），但每一处示意都在画面角落注明，光照与遮挡一律按真实位置算。

### 1. 场景

- 1 单位＝1000 km；原点＝球心；+y＝塔顶；与 01 的地固系同轴（不做 CM 旋转）。
- 相机：`PerspectiveCamera(38°)`，`OrbitControls`（阻尼 0.08，不平移，距离 1.2–90 单位）；`near = max(0.002, 0.004·相机到目标距离)`，`far = 相机到原点距离＋15`，每帧更新，不用对数深度。
- 惯性系（`ov.frame='inertial'`）：把“随星体转”的一组（内壁、塔面纹理、地点、标签锚点）绕 y 转 `geom.spin(P, t)`（＝frac(Ω·86400·t／2π)·2π，用小数圈避免大角度），日月用 `HY.astro.toInertial`。外侧星空在惯性系里不动，在地固系里每 71.3 分转一圈；总览流速超过 ×3600 时星空淡出（否则只剩闪烁）。

### 2. 内壁（`shell.js`）

半径 R 的球面（192×128 段），自定义 `ShaderMaterial`（GLSL1 写法，`ov_shell.vert/.frag`），逐片元：

| 项 | 算法 |
|---|---|
| 底色 | 按 `g = gEq·|X.xz|/R` 与 `|y|` 归域，取域色（CSS 变量 `--z-*` 转线性）；分域边界 ±1% 处软过渡 |
| 日照 | `E = (Dref/|S−X|)²·max(0, n·l)·towerVis(X, S, ρS)·eclipseVis(X)`，n＝指向球心的内法线；显示值 `base·(0.10 + 0.90·sqrt(min(E,1.3)))` |
| 夜（塔影里） | `base·0.06 ＋ 夜色·0.05`（夜色 `--sky-night`）；半影按 `towerVis` 的 0–1 连续过渡，影边是一条沿经线方向的直线软边 |
| 日食月影 | `eclipseVis` 直接乘进日照，月影在壁上是一个移动的暗斑（只在罪域以南的季节出现） |
| 网格 | ψ 每 15°、φ 每 30° 一条细线（`fwidth` 抗锯齿，`ov.grid`）；赤道、轻／平、平／重分界用域色描边 |
| 剖切 | `ov.cut='half'`：`dot(X, uClipN) > 0` 的片元丢弃（uClipN＝从原点指向相机的单位向量），剖口画一圈 `--line2` 色的环；`'ghost'`：近侧不丢弃、改成 0.18 透明并关深度写入；`'none'`：完整 |
| 外侧（背面） | `gl_FrontFacing` 为假时画外表面：暗石色＋程序星点（`ov.stars`），角落标签“外表面·神的国” |

`towerVis`、`eclipseVis` 在 `glsl/ov_occl.glsl` 里，是 02 `common.glsl` 同名函数的逐字副本（外加 `#define PI`、`sq()`、`uniform float uA`），`test/glsl_check.js` 断言两边函数体一致。

### 3. 巨塔

半径 a、长 2.12R 的圆柱（两端穿出内壁，示意它连通外表面）。近黑（反射率 0.012）加一道很弱的视角边缘光（菲涅耳 0.05），否则在黑背景上看不出圆柱的体感；塔腰（y＝0）处一道细环。标签：塔根·北极、塔顶·南极、塔腰。

### 4. 日与月（`bodies.js`）

- **太阳**：真实位置 `HY.astro.sunPos(t)`；本体半径 `min(ρS·bodyScale, 0.8·(dS−a))`（不穿进塔），自发光；外加屏幕空间光晕精灵（加色，深度测试，转到塔后自然被挡）。`ov.sunGapX>1` 时，太阳本体、示意螺旋、实际轨迹都画在离轴 `a + (dS−a)·sunGapX` 处（同方位、同高度），角落写“示意：日轨离塔面放大 ×N（实为 40 km）”；**内壁光照、塔影、视线一律仍按真实位置算**。
- **月亮**：真实位置 `HY.astro.moonPos(t)`；显示半径 `ρM·bodyScale`；`ov_moon.frag` 逐片元：法向 n，物理采样点取 `月心 + n·ρM`（真半径，保证影边位置正确），`亮 = max(n·l, 0)·towerVis(采样点, S, ρS)`，于是灰月时一道直的影边扫过月面；暗面给 0.05 的“对岸光”底色，黑月因此是深灰而不是纯黑（01 第九节第 4 条的意思，示意值）；月面加少量程序斑纹。标签随月态改成“月（亮月／灰月／黑月）”。
- `ov.showMoon` 为假时隐藏月亮及其螺旋。

### 5. 螺旋轨迹（作者这次要的“优美”就落在这里）

01 的事实：日、月都绕塔、一年沿塔身上下一个来回，高度互为镜像（`yM ≡ −yS`），所以两条螺旋**旋向相反**，入冬、入夏两刻同过塔腰；太阳 640 km 内圈、月亮 R/2 外圈。按实比例，太阳一年 360 圈、圈距最大约 56 km，贴着塔面只是一层金色薄壳，看不出螺旋。所以总览提供四种画法（`ov.helix`）：

| 画法 | 画什么 | 怎么算 |
|---|---|---|
| **镜像双螺旋**（默认，示意） | 日、月各一条管状螺旋，**同样**每年 `helixTurns` 圈（默认 12），日在内圈（离轴 640 或放大后的半径）、月在外圈（rM），高度按真实的 `±A·sin(2πu)`。两条恰成一对旋向相反的螺旋，在塔腰交会 | 几何只建一次：参数 u∈[0,1)，`角 = 2π·turns·u`，`高 = ±A·sin(2πu)`；每帧把整条螺旋绕 y 转 `θ(t) − 2π·turns·u(t)`（u(t)＝年相位），保证它**穿过天体的真实位置**——零几何重建 |
| 实际轨迹 | 前后各 0.5 日（日）、1 日（月）的真实路径，渐隐的彗尾；另画两只淡色包络圆筒（r＝dS 与 rM，y∈[−A, A]） | 每帧重写约 200 个顶点（`geom.trail`） |
| 每日同刻 | 一年里每天同一时刻（当前钟点）的位置：太阳落在一条竖直线上（只上下），月亮连成一条一年 12¼ 圈的螺旋 | 静态几何，日期换年或参数变时重建 |
| 关 | 只画天体 | — |

- **着色**：管子用 `ov_helix` 着色器，顶点属性 u（年相位）。离“此刻”越近越亮（前后各四分之一年衰减到 25%），过去略冷、将来略暖；日螺旋金色 `--sun`，月螺旋银蓝 `--moon`；冬半年段（塔根半球）与夏半年段明暗略有区别，读得出“往上是入冬”。
- **交节标记**：两条螺旋在塔腰各有两处交节点（入冬、入夏），画小环；当前年入冬交节若是庆典年，在交节那一刻的日、塔轴、月三点之间画一条极细的白线，标“三点一线·圣皇庆典”。
- **示意说明**：画面左下角常驻一行小字，如“示意：螺旋每年画 12 圈（实为日 360 圈、月 348 圈）”。

### 6. 塔影

- 内壁上的夜就是塔影（第 2 条），始终按真实太阳算。
- **塔影体**（`ov.shadowVol`）：由真实日心与日面两缘对塔作切线，得本影、半影四条边界（`geom.shadowWedge`）；从塔面切点沿切线方向画到内壁的竖直半透明面（y 方向贯通 −R..R，着色器里丢弃球外片元），本影面暗灰 8% 不透明、半影面更淡；与内壁交线描一条细线。这就是“黑夜是一道贯通两极的楔形影”。
- **视线**（`ov.sight`）：从当前地点到日、到月各一条线段；被塔挡住时变成红色虚线。

### 7. 分域与地点

- 分域环：轻／平、平／重、灵薄带两侧的纬线环（塔根与塔顶两半球都画）；图例在顶栏下方。
- 地点针：`HY.world.SITES` 每处一根沿“上”（指向塔轴）的短针＋圆点，当前地点白色加粗；第一人称用过后，当前地点处多一个小锥，指向 `fp.yaw/pitch`（“刚才站在这里、朝这边看”）。

### 8. 标签（`labels.js`）

HTML 层 `#labels`，每帧投影约 20 个锚点。隐藏规则：在相机背后、被剖掉的一侧、被塔挡住（射线与圆柱求交）、被内壁挡住（锚点在球面背向相机的一侧且未剖开）。同屏标签按优先级（当前地点＞日月＞两极＞其它地点）做简单避让：后画的与已画的矩形重叠就隐藏。

### 11. 呈现

### 1. 公共接口（`charts/base.js`）


### 6. 物理推论说明（`ui/notes.js`，v3 改写，数字随参数）

1. **只有两季**：日在塔腰以上时塔根半球为冬；冬夏各半年。
2. **昼夜不随季节变**：夜就是塔影，宽窄只看日轨离塔多远；此地常年昼 X、夜 Y 小时。
3. **日不行天，只过塔**：一日五段；离塔中线最多 Z°；重力仰角正午最低。
4. **日月镜像**：日升则月降，旋向相反；入冬、入夏两刻同过塔腰；罪域是日月的回归线。
5. **黑月就是月亮自己的夜**：黑月占一月 44.7%，与离轴 R/2 处夜占一日是同一公式。
6. **四年一度，三点一线**：一年 12¼ 月，入冬那一刻的月相每年转四分之一圈；庆典年列表与余量。
7. **冬月高而半，夏月低而圆**。
8. **重力方向与阶地**：“上”指向塔轴；地面倾角＝纬度，此地 X°；往塔走就是往上爬。
9. **往外就是往下**：赤道最低，可安放深渊；余息是入冬前塔根先冷、冷风顺坡外泄。
10. **没有星星**：视线最后都落在对面内壁；只有外表面（神的国）有星空，它每 71.3 分转一圈。
11. **夜不全黑**（设定开关）：子夜对岸光上限约 8–9 klux，是月光的千倍以上；静滞夜幕可把它压下去。
12. **白天几乎看不见巨塔、没有红色落日**：大气标高 40 km 时正午塔带只比旁边暗 1.2 倍；日落发生在高处，气路短，不变红。
13. **空气与自转**：纯物理下空气沉向赤道，需要静滞按住；赤道 1.4g 要求每 71.3 分自转一圈。
14. **日食**：只在涅赫莱恩以南看得到，两京永远看不到；此地四年约 N 次。

```
loop(now):
  dtReal = clamp((now − last)/1000, 0, 0.1)
  if (state.time.playing) store.set('time.t', t + dtReal·speed/86400, 'play')     // speed 取当前视图的档
  HY.model.tick()
  ctx = {t, dtReal, dtSim, w, h, now: HY.model.now}
  active view .frame(ctx)                 // HY.ov 或 HY.fp
  bus.emit('frame', ctx)                  // HUD、标签、图表游标（各自节流）
  requestAnimationFrame(loop)
```

页面隐藏（`visibilitychange`）时暂停推进时间（不改 `playing`）、停止出图；回来后 `dtReal` 夹在 0.1 s 以内，不会一下跳很远。
