## 〇、定稿结论

**一句话**：解析天体＋凹面弦表大气＋逐像素地形求交＋低分辨率体积＋人眼后期。巨塔、日、月、对面内壁全部逐像素解析求交，锐利、精确、几乎不花钱；脚下到 400 km 的地形由“粗分辨率包络求交＋全分辨率精化”逐像素算出，峭壁轮廓精确到像素；空气与云这类柔和的体积在 1/4 或 1/2 分辨率上积分，并做时域累积；0–300 m 内用实例化的石块、草、枯木、干砌石墙给出人身边的尺度。最后按人眼而不是相机做曝光、色适应、暗视觉和眩光。

**选型**：三位评审两位判方案C胜（凹面弦表混合写实管线），一位判方案A胜。按多数取 C 作骨架：CM 坐标系、K 精度体系、弦表、三行空腔探针、半分辨率远场、全分辨率解析合成（塔、日、月 4 子样）、three r128 接入方式都照 C。C 的短板（合成次序、网格太短太粗、阶地规整、云规整、无时域累积、中档无阴影、无尺度参照）按评审意见用 A、B 的做法补齐。

**对 C 骨架的三处结构性改动**（理由都来自评审）：

1. **合成次序**：地形和实例先画，只出“表面辐亮度＋命中距离”，不带大气；近段体积 pass 积分到 min(地形距离, 近段出口)，云和空气在同一次积分里按先后合成。C 原型“先合成天空、再盖地形网格、逐顶点 8 步空气透视”的做法删除（评审 1、3 第 1 条）。
2. **近处地形不用网格**：C 的可分离指数网格每格约 5°（在 1080p 上约 100 像素），画不出崖线；拉长到 30 km 也一样粗，还有网格与步进的接缝（评审 1 第 2 条、评审 3 第 2 条）。改为逐像素求交：1/4 分辨率先做一遍“包络求交”给出安全起点，全分辨率只精化十几步。这样 0–400 km 是同一个高度函数、同一种求交，没有接缝，峭壁轮廓逐像素精确，也没有网格“游动”。实例物件仍是光栅化网格，按地形写出的深度做遮挡。
3. **贴地由 GPU 自定**：地形高度一律写成“相对相机脚下”的差分，脚下各层的取值由一个 1×1 的 pass 在同一张纹理上自取。于是 GPU 上相机离地恒等于眼高，CPU 只需近似高度做碰撞，不再要求 CPU、GPU 逐位一致（评审 2 第 6 条、评审 3 第 9 条）。

**与正典的总判断**（细节见第十九节）：按纯物理，夜是对面白昼照下来的“白夜”，子夜地面照度是正午的约八分之一；正午的塔几乎被天光吞没，黄昏和夜里才是“黑带劈开天空”；没有贴地平线的红色落日。渲染器如实画出，并把照度读数和“设定”旋钮放在明面上，不偷偷把夜调黑。

## 二、与 01（天体与历法）的对接

渲染器**只吃位置、半径和定标**，不对轨道作任何假设。月亮改走与太阳对称的螺旋（01 第三节）在渲染层不需要任何特殊处理：月离内壁最近 1866 km、视径最大约 5°、与太阳最近 2546 km 时受照增强约 5 倍，这些都会自动出现在画面上。

| 渲染器要的 | 从哪里取 | 备注 |
|---|---|---|
| 参数表 P | `HY.astro.params(覆盖项)` | 改参数时重建；渲染相关的覆盖项见附录 B |

| 日、月半径 | `P.rhoS`（20）、`P.rhoM`（100） | |
| 光度定标 | `P.Eref`（71.5 klux）在 `P.Dref`（5731 km）处 | `uSunI = Eref·Dref²·日色`，按 1/d² 衰减 |
| 月面反照率 | `P.pMoon`（0.6，几何反照率） | 换算见第十一节第 3 条 |

| 对岸光上限 | `farLight(X, n, t, P)` | 只用于测试对拍（第十八节），不进帧循环 |

**口径的三处说明**（交回 01 备查，不改 01）：

1. **垂直光学厚度**：01 用 τ＝3.912·H／V＝0.78 作便捷估算。渲染器的口径是“壁面处消光 3.912/V，瑞利、米氏各按自己的标高衰减”：H_R＝40、H_M＝6、V＝200 时，绿光垂直光学厚度＝0.542（瑞利）＋0.036（米氏）＝0.58，蓝 1.36，红 0.27。HUD 与测试以渲染器口径为准。
2. **日色**：5772 K 黑体在线性 sRGB 里（亮度归一）为 (1.104, 0.978, 0.919)。`uSunI` 乘这个色。
3. **夜间对岸光**：01 的 `farLight` 不计大气、只算一次反弹，是 8.4–9.1 klux 的上限。渲染器有大气和多次反弹，实测值应落在上限的 0.6–1.1 倍之间（多次反弹加一点、两层大气减一点），第十八节有断言。

## 三、坐标、单位与精度规则

1. **CM 系**：把地固系绕塔轴转 −φ_C，使相机经度＝0。原点＝球心，+y＝塔轴指向塔顶，塔根极在 (0, −R, 0)。相机在 (ρ_C, y_C, 0)，ρ_C＝相机离塔轴的距离。相机处：上 U＝(−1, 0, 0)（指向塔轴，即重力“上”），北 N＝(0, −1, 0)（朝塔根），东 E＝(0, 0, −1)。地固系 → CM 系：x′＝x·cosφ_C＋z·sinφ_C，z′＝−x·sinφ_C＋z·cosφ_C，y 不变。CM → 地固：φ＝atan2(z′, x′)＋φ_C。
2. **高度一律从 K 推**：K＝|p|²−R²，离壁高度 z＝−K／(R＋√(R²＋K))。相机的 K 由 CPU 双精度算；视线上 t 处 K(t)＝K_C＋t·(2·(C·d)＋t)。不写 R−|p|。
3. **相机相对差分**（地形专用，0.5 m 以下的精度都靠它）：
   - 离轴半径差 Δρ＝(2p·w＋w²)／(ρ_C＋√(ρ_C²＋2p·w＋w²))，p、w 取 xz 分量；
   - 球面半径差 Δρ_s＝−(2y_C·Δy＋Δy²)／(ρ_s(y_X)＋ρ_s(y_C))；
   - 离球心距离差同理；
   - 小角度一律 `sinS()`（|x|＜0.02 用级数）；位移用差角公式 cosψ_C−cosψ＝2·sin(ψ_C＋Δψ/2)·sinS(Δψ/2)。
4. **地面图表坐标**（评审 2 第 1 条的根治）：所有程序纹理都按同一张二维图表取样，原点与差分用同一个量。
   - 阶地模式：c＝(−R_ref·φ, −y)。北向用 −y，因为踏面水平，水平向北的距离就是 −Δy。
   - 斜坡模式：c＝(−R_ref·φ, −R·ψ)。北向用地面弧长。
   - R_ref＝瞬移时所在处的 ρ，行走时不变（不变才不会滑动；离开 500 km 后东向尺度偏 10% 以内，可以接受）。
   - GPU 差分：Δc_E＝−R_ref·atan(v.z, ρ_C＋v.x)；阶地 Δc_N＝−v.y；斜坡 Δc_N＝−R·atan(y_C·Δρ−ρ_C·Δy, ρ_C(ρ_C＋Δρ)＋y_C(y_C＋Δy))（两个大数的差在解析上已消去）。
   - CPU 原点：第 k 层 `uOrg[k] = fract(Rot_k · c_C / (L_k · 32))`，双精度。
   - 测试：相机走 1 km 后，固定地物的纹理坐标变化＜1 mm（test/chart_slide）。
5. **深度**：不用顶点版对数深度（会翻转跨相机的三角形，C 的教训）。地形全分辨率 pass 用 `gl_FragDepth` 写出与实例相机同一投影的深度（near 0.1 m，far 3 km），3 km 以外写 1。
6. **半精度与预曝光**：中间缓冲（地形、近段、远场、探针）存场景单位（kn），不预曝光；fp16 上限 65504 kn 足够（天空最亮约 30 kn）。只有合成后的 HDR 乘上一帧曝光再写入，并夹在 6×10⁴ 以内；日面（约 3.3×10⁶ kn）在 HDR 里被截断，它的眩光在最终 pass 按物理照度解析叠加。
7. **哪些用 float32 目标**：弦表（有 OES_texture_float_linear 时）、脚下 1×1、地形粗求交（距离要保守，不能被 fp16 舍入抬高）。其余 RGBA16F。

## 四、帧管线

### 1. 每条视线的分段

从相机出发的视线 C＋t·d，记 cd＝C·d：

```
t_wall  = −cd + √(cd² − K_C)                      撞内壁（总在）
t_tower = 圆柱求交（可能没有）
t_ap    = −cd                                     视线离球心最近处（弦的中点）
[a1,b0] = 与真空核（半径 R − Ztop）的交段；没交到时 a1 = b0 = t_ap
t_s     = 地形或实例命中（地形 pass 给出，没有为 −1）
t_end   = min(t_s, t_tower, t_wall)
近段 = [0, min(a1, t_end)]；t_ap ≤ 0（视线朝地）时近段 = [0, t_end]
真空 = (a1, b0)，只在 a1 < t_end 时存在；暗幕在这里吸收
远段 = [b0, t_end]，只在 b0 < t_end 时存在
```

日、月、真空里的那段塔只可能出现在真空段；对面大气里的塔脚在远段；离塔根很近时近处的塔可能在近段。三段各由一个 pass 负责，交接处只用解析量，所以永远对得上。

### 3. 合成式

```
L_px = S_near + Tx · Tair(0, e) · L_e

e     = 近段终点 = min(a1, t_end)（视线朝地时 = t_end）
S_near, Tx = 近段 pass 的输出：内散射（含云、雨、余息、酸霾）与“弦表之外”的灰透射（云×局地介质）
Tair  = 弦表两次查表给出的瑞利＋米氏透射（带色）
L_e   = 近段终点处朝相机的辐亮度：
        终点是地形／实例  →  tSurf.rgb
        终点是近处塔      →  塔面辐亮度（解析）
        进入真空          →  4 子样：日／月／真空段的塔，按距离取最近者；都没有则 V·L_far
L_far = 远段 pass 输出（远段内散射＋远段透射×对面内壁或塔脚）
V     = exp(−k_veil · 真空段长度)（静滞暗幕，默认 k_veil = 0）
```

云和空气的先后次序在近段 pass 内部按样本位置排好（第十二节第 2 条），这就是 A 的“云深度快照”合成式在单个 pass 里的实现：地形、云、空气一次积分里合成，崖顶插进罪域云底时次序自然正确。

## 五、CPU 每帧（JS 双精度）

```
P      = HY.astro.params(覆盖项)                       // 参数改动时重建
t      = 模拟时刻（日）                                  // 实时：每秒 1/86400 日 × 流速
S_w    = HY.astro.sunPos(t, P)；M_w = HY.astro.moonPos(t, P)
```

**相机状态**：地点 (s, φ) 或行走中的图表坐标。两种地面模式分别保存：

- 阶地：(y_C, φ_C)；地面离轴 r_g(y, φ)＝Hc·(k＋S(f))−d_fine，见第八节第 3 条；相机 ρ_C＝r_g−eye。
- 斜坡：(ψ_C, φ_C)；脚点 F＝(R−D)·F̂，相机 C＝F＋eye·U。

两种都先算出地固系相机位置，再转 CM 系（x′＝ρ_C，z′＝0），然后：

```
C_f      = fround3(C_cm)                               // 以下全用舍入后的值
uCamW    = C_f；uCamRho = C_f.x
uCamK    = C_f.x² + C_f.y² − R²                         // 双精度
uCamZ    = −uCamK / (R + √(R² + uCamK))
uRsC     = √(R² − C_f.y²)
uLamCam  = φ_C
uSunW    = toCM(S_w)；uMoonW = toCM(M_w)                // 双精度旋转后再 fround
uSunI    = P.Eref·P.Dref²·(1.104, 0.978, 0.919) / 1000  // klux·km²
uMoonBasis：z_b = −(M.x,0,M.z)/|·|（一面朝塔轴），y_b = (0,1,0)，x_b = y_b × z_b
uOrg[k]  = fract(Rot_k · c_C / (L_k · 32))              // c_C 见第三节第 4 条
uTerF0   = fract(q_C)，q_C = (ρ_s(y_C) − P_low(C))/Hc − wig·w(C) − jit·b(C)   // 用 JS 镜像函数，近似即可
uCamAlt  = 阶地：eye；斜坡：eye·sinψ_C                   // eye = 0.0016 km
uHc      = min(Hc_用户, W_max·|y_C|/ρ_s(y_C))，W_max = 20 km；纬度 < 2° 自动退回斜坡模式
uLip、uClearMax、uAmpZone：见第八节第 4 条
```

**相机朝向**：yaw（自北向东）、pitch（相对重力水平），横滚恒 0。

```
fwd   = cos(pitch)·(cos(yaw)·N + sin(yaw)·E) + sin(pitch)·U
right = normalize(fwd × U)；up = right × fwd
```

**上一帧量**（TAA、近段时域）：上一帧相机位置与基向量在**本帧 CM 系**里的表示（相机经度变了，要先旋转）、上一帧抖动、上一帧曝光、模拟时间步长 Δt_sim。

**HUD 量**：`HY.astro.sky(O, t, P)`（日月方位、仰角、视径、露出、月态）、`dateOf`、`localHour`；照度读数来自 pass 13 的 1×1 结果，延迟一帧读回（`readRenderTargetPixels` 读 1×1 浮点，异步、每 0.5 s 一次，不卡帧）。

**行走与碰撞**：CPU 用 JS 镜像的地面函数（同一套整数哈希与同一套层参数，解析求值，不读纹理）求脚下高度，与 GPU 的差在 0.3 m 以内即可，因为 GPU 上的眼高由 pass 2 自定（第八节第 2 条）。前方 1 m 内高差超过 0.6 m（崖）就停步；崖沿可以站，崖面不能站（阶地相位落在崖带里时退回上一步）。

```glsl

#define PI 3.14159265359
#define INF 1e30
// ---- 画质（material.defines 覆盖；默认＝中档） ----

#endif

#endif
#ifndef Q_TER_FAR_KM

// ---- 星体与相机（CM 系，km） ----
uniform float uR, uA, uZtop;                 // 6371；600；大气顶离壁高度

uniform float uCamK, uCamZ, uCamRho;          // |C|²−R²；离壁高度；离塔轴

uniform float uHR, uHM, uMieG;                // 40、6、0.76

uniform vec3  uRuiDir; uniform float uRuiRad; // 罪域中心方向（CM 单位向量）、半径（km，沿地面）
uniform float uRainBeta;                      // 罪域云底下雨雾消光 /km

uniform vec3  uAcidTint;                      // 酸霾散射色（偏硫黄）
uniform vec4  uYuxi;                          // 余息：x 壁面消光 /km，y 前锋（离塔根地面距离 km），z 标高，w 前锋宽
uniform vec2  uSheath;                        // 塔缘气层：x 塔面处消光 /km（0＝关），y 标高 km
uniform sampler2D uTau; uniform vec2 uTauSize;
uniform sampler2D uMS;  uniform sampler2D uSkyLUT;
uniform sampler2D uSH;                        // 9×3：行 0 相机全天，行 1 大气之外，行 2 从月亮看
// ---- 地面 ----
uniform int   uGroundMode;                    // 0 顺球面斜坡；1 水平阶地＋崖
uniform sampler2D uHeight;                    // R 高度[-1,1]，GB 对 uv 偏导，A 材质噪声
uniform sampler2D uFoot;                      // 1×1 RGBA32F：脚下各层取值（pass 2）
uniform vec2  uOrg[7];                        // 各层图表原点（CPU 取模）
uniform float uRref;                          // 图表东向比例半径
uniform float uHc, uCliffC, uResid;           // 崖高 km、崖带占比、踏面余坡
uniform float uWig, uJit;                     // 蜿蜒、扶壁（以级为单位）
uniform float uTerF0, uRsC, uCamAlt;          // 相机处阶地相位小数；ρ_s(y_C)；相机离地
uniform float uAmpZone, uLip, uClearMax;      // 起伏系数；位移坡度上界；最大起伏 km
uniform float uAbyssDepth, uAbyssHalf, uLimboKm;
uniform float uGEq, uGLight, uGHeavy, uWet;
uniform sampler2D uHorizon; uniform vec4 uHzLvl[3];   // 3 级：xy 级中心相对相机的图表偏移，z 半宽 km，w 有效
uniform sampler2D uCloudSh; uniform vec3 uCsInfo;     // 云影图：xy 中心偏移，z 半宽
uniform sampler2D uWorld;                     // 2048×1024 等面积 (φ,y)：rgb 反照率，a 水面
// ---- 云 ----
uniform float uCloudOn, uCloudBase, uCloudTop, uCloudSigma;
uniform float uRuiOvc, uRuiBase, uRuiTop, uRuiTau;
uniform sampler2D uWeather;                   // 1024×512 等面积 (φ,y)：r 覆盖，g 类型(0 层云…1 积云)，b 厚度系数，a 降水
uniform sampler3D uNoise3, uNoise3D;
uniform vec3  uWind; uniform float uJetPhase;

// ======================= 0. 工具 =======================
float sq(float x){ return x*x; }
float sat(float x){ return clamp(x, 0.0, 1.0); }
float lum(vec3 c){ return dot(c, vec3(0.2126, 0.7152, 0.0722)); }
float sinS(float x){ float x2 = x*x; return abs(x) < 0.02 ? x*(1.0 - x2*(1.0/6.0)*(1.0 - x2*0.05)) : sin(x); }
float sstep(float a, float b, float x){ float u = clamp((x - a)/(b - a), 0.0, 1.0); return u*u*(3.0 - 2.0*u); } // 允许 a>b
float ign(vec2 p, int f){ p += float(f & 63)*5.588238; return fract(52.9829189*fract(dot(p, vec2(0.06711056, 0.00583715)))); }
vec3 viewRay(vec2 fc, vec2 res, vec2 jitFull, float scale){   // scale＝本 pass 相对全分辨率的倍数
  vec2 ndc = (2.0*(fc + jitFull*scale) - res)/res.y;
  return normalize(uCamFwd + uTanHalfFov*(ndc.x*uCamRight + ndc.y*uCamUp));
}

// ======================= 1. 求交（相机用 K，其余用稳定二次根） =======================
float Kat(float t, float cd){ return uCamK + t*(2.0*cd + t); }
float zOfK(float K){ return -K/(uR + sqrt(max(uR*uR + K, 0.0))); }
float Kof(vec3 X){ return dot(X, X) - uR*uR; }                  // 非相机点：误差约 2 km²，高度误差约 0.2 m
float tWallCam(float cd){ return -cd + sqrt(max(cd*cd - uCamK, 0.0)); }
vec2 tShellCam(float cd, float z){                               // 离壁高度 z 的球壳
  float c = uCamK + z*(2.0*uR - z), D = cd*cd - c;
  if (D < 0.0) return vec2(-1.0);
  float s = sqrt(D); return vec2(-cd - s, -cd + s);
}
vec2 iSphere(vec3 o, vec3 d, float rad){
  float b = dot(o, d), c = dot(o, o) - rad*rad, D = b*b - c;
  if (D < 0.0) return vec2(INF, -INF);
  float s = sqrt(D), q = -b - (b >= 0.0 ? s : -s);
  if (abs(q) < 1e-20) return vec2(0.0);
  float t1 = q, t2 = c/q; return vec2(min(t1, t2), max(t1, t2));
}
float iTower(vec3 o, vec3 d){                                    // 沿 y 的无限长圆柱，返回首个正交点
  vec2 od = o.xz, dd = d.xz; float A = dot(dd, dd);
  if (A < 1e-14) return INF;
  float B = dot(od, dd); if (B >= 0.0) return INF;
  float cr = od.x*dd.y - od.y*dd.x, D = A*uA*uA - cr*cr;         // 无相消的判别式
  if (D < 0.0) return INF;
  float t = (-B - sqrt(D))/A; return t > 0.0 ? t : INF;
}
// 视线分段（第四节第 1 条）：x 近段终点 e，y 远段起点 b0，z t_end，w 1＝有真空段
vec4 segments(float cd, float tEnd){
  if (-cd <= 0.0) return vec4(tEnd, INF, tEnd, 0.0);            // 视线朝地：全部给近段（评审 2·9）
  vec2 core = tShellCam(cd, uZtop);
  float a1 = -cd, b0 = -cd;
  if (core.y > 0.0){ a1 = max(core.x, 0.0); b0 = core.y; }
  return vec4(min(a1, tEnd), b0, tEnd, (core.y > 0.0 && a1 < tEnd) ? 1.0 : 0.0);
}

// ======================= 2. 遮挡 =======================
// 从 X 看半径 rho、中心 S 的发光球露在塔外的面积比例。带边＝过 X 且与塔相切的竖直平面，日面被切出弓形（闭式）
float towerVis(vec3 X, vec3 S, float rho){
  vec2 p = X.xz; float rp2 = dot(p, p), a2 = uA*uA;
  if (rp2 <= a2) return 0.0;
  float rp = sqrt(rp2); vec2 q = S.xz - p; float Lh = length(q);
  if (Lh < 1e-3) return 1.0;
  vec2 c = -p/rp; float cosA = dot(q, c)/Lh;
  if (cosA <= 0.0) return 1.0;
  float sinA = abs(c.x*q.y - c.y*q.x)/Lh, sd = uA/rp, cdd = sqrt(max(1.0 - sd*sd, 0.0));
  float u = Lh*(sinA*cdd - cosA*sd)/rho;                         // 日心到带边平面的有符号距离／半径
  if (u >= 1.0) return 1.0;
  if (sinA < sd){ float tHit = rp*cosA - sqrt(max(a2 - rp2*sinA*sinA, 0.0)); if (Lh < tHit) return 1.0; }
  else if (Lh < rp*cdd) return 1.0;                               // 日在切点之前（塔前）
  if (u <= -1.0) return 0.0;
  return 0.5 + (u*sqrt(1.0 - u*u) + asin(u))/PI;
}
float eclipseVis(vec3 X){                                        // 月掩日：日面露出比例（透镜面积闭式）
  vec3 ds = uSunW - X, dm = uMoonW - X; float Ds = length(ds), Dm = length(dm);
  if (Dm >= Ds || dot(ds, dm) <= 0.0) return 1.0;
  float r1 = uSunRho/Ds, r2 = uMoonRho/Dm, sep = length(cross(ds/Ds, dm/Dm));
  if (sep >= r1 + r2) return 1.0;
  if (sep <= r2 - r1) return 0.0;
  if (sep <= r1 - r2) return 1.0 - sq(r2/r1);
  float x = (sep*sep + r1*r1 - r2*r2)/(2.0*sep);
  float A = r1*r1*acos(clamp(x/r1, -1.0, 1.0)) + r2*r2*acos(clamp((sep - x)/r2, -1.0, 1.0)) - sep*sqrt(max(r1*r1 - x*x, 0.0));
  return 1.0 - A/(PI*r1*r1);
}
float veilT(vec3 X, vec3 S){                                     // 暗幕：X→S 连线在真空核里的长度
  if (uVeilK <= 0.0) return 1.0;
  vec3 dv = S - X; float L = length(dv);
  vec2 c = iSphere(X, dv/L, uR - uZtop);
  if (c.x >= c.y) return 1.0;
  return exp(-uVeilK*clamp(min(c.y, L) - max(c.x, 0.0), 0.0, L));
}

// ======================= 3. 弦表（凹面透射） =======================
// W(α_w, z)：弦上离壁高度 z 处沿弦“向外”到内壁的光学厚度（RGB）；弦由它在内壁处与切面的夹角 α_w 决定
vec3 chordW(float al, float z){
  float zmax = min(uZtop, 2.0*uR*sq(sinS(0.5*al)));
  vec2 uv = vec2(sqrt(clamp(al/(0.5*PI), 0.0, 1.0)), sqrt(clamp(z/max(zmax, 1e-6), 0.0, 1.0)));
  return textureLod(uTau, uv*(1.0 - 1.0/uTauSize) + 0.5/uTauSize, 0.0).rgb;
}
float alphaOf(float K, float pd){ return asin(clamp(sqrt(max(pd*pd - K, 0.0))/uR, 0.0, 1.0)); }  // pd＝X·d
```

**要点**：

- `towerVis` 与 `HY.astro.diskVisible` 是同一个量的两种写法（前者用带边平面的有符号距离，后者用方位角差），test/tower_vis 在 1 万组随机点上对拍，误差＜1e-4。

- `cavityE` 的依据：在漫反射球腔里，任一壁面元看任一其它壁面元的形状因子都等于 dA/(4πR²)，所以第一次以后的壁间照度处处相同；这里只修正塔挡掉的那一份。探针行 1 在相机处测到的就是这个量（含两层大气的削减），远壁、云顶、塔面直接用。test/cavity 拿它对拍 `HY.astro.farLight`。

### 1. 密度剖面（贴壁，设定：被静滞按在内壁上）

### 2. 决定一切的几何事实

日心离球心不超过 √(640²＋(R/2)²)≈3250 km。所以从内壁任何一点看，太阳永远在“球心方向”30.7° 以内，日光最多穿过 1.16 个垂直气柱。由此：

- 这个世界**没有穿过长气路而变红的落日**。太阳全天同色，日没是被塔缘切掉，不是沉向地平线。
- 唯一能让太阳偏橙的是日面被塔缘切到最后一线时的**临边昏暗**：临边昏暗系数按波长取 u＝(0.55, 0.70, 0.85)（红、绿、蓝），最后几分钟那一线残日偏暗偏橙。这正是 01 第十四节第 16 条说的“一线橙边”，渲染器原生支持。
- 另有可选的“塔缘气层”（第 10 条），默认关。

### 3. 弦表 `lut_tau.frag`（256×128，参数改变时算一次）

凹面世界里每条视线都是内壁的一根弦，两头在大气里，中间是真空。弦由它在内壁处与切面的夹角 α_w 唯一确定（冲距 b＝R·cos α_w）。W(α_w, z)＝弦上高度 z 的点沿弦向外到内壁的光学厚度；过了弦中点用 2W(顶)−W(z)。任意两点之间的透射只需两次查表，地平线处没有 Bruneton 表的跳变。存光学厚度，不存透射率（fp16 下透射率会下溢）。

```glsl
// lut_tau.frag：拼在 common 之后
layout(location = 0) out vec4 oc;
void main(){
  vec2 uv = clamp((gl_FragCoord.xy/uTauSize - 0.5/uTauSize)/(1.0 - 1.0/uTauSize), 0.0, 1.0);
  float al = uv.x*uv.x*0.5*PI;
  float zmax = min(uZtop, 2.0*uR*sq(sinS(0.5*al)));
  float z = uv.y*uv.y*zmax;
  float b = uR*cos(al), xR = uR*sinS(al);
  float xz = sqrt(max(xR*xR - z*(2.0*uR - z), 0.0));            // (R−z)²−b²，不相减
  float span = z*(2.0*uR - z)/max(xR + xz, 1e-6);                // xR − x(z)，不相减
  vec3 tau = vec3(0.0);
  const int N = 192;
  for (int i = 0; i < N; i++){
    float s0 = float(i)/float(N), s1 = float(i + 1)/float(N), sm = 0.5*(s0 + s1);
    float dx = span*(sq(1.0 - s0) - sq(1.0 - s1));               // 向内壁一端二次加密
    float dxR = span*sq(1.0 - sm), x = xR - dxR;
    float zz = dxR*(xR + x)/(uR + sqrt(b*b + x*x));              // 高度＝(xR−x)(xR+x)/(R+ρ)
    tau += (uBetaR*exp(-zz/uHR) + vec3((uBetaMs + uBetaMa)*exp(-zz/uHM)))*dx;
  }
  oc = vec4(tau, 1.0);
}
```

### 4. 多次散射表 `lut_ms.frag`（32×32，(μ_s, √(z/Ztop))）与本地天光表 `lut_sky.frag`（64×1）

Hillaire 2020 的 Ψ_ms 改成凹面：朝里的射线穿出大气顶即止，朝外的打到内壁并计地面反照（0.15）。对面世界照进来的光**不放进这张表**，而是在每个空气样本上单独加“空腔项”σ_s·L_cav（第 6 条），这样不会重复，也不会漏（评审 2 第 3 条）。

```glsl
// lut_ms.frag：拼在 common 之后
uniform float uGroundAlb;
layout(location = 0) out vec4 oc;
void main(){
  vec2 uv = (gl_FragCoord.xy - 0.5)/31.0;
  float mus = uv.x*2.0 - 1.0, z = uv.y*uv.y*uZtop;
  vec3 P0 = vec3(0.0, -(uR - z), 0.0);                            // 内法线＝+y
  vec3 ls = vec3(sqrt(max(1.0 - mus*mus, 0.0)), mus, 0.0);
  float K0 = -z*(2.0*uR - z), Rt = uR - uZtop;
  vec3 L2 = vec3(0.0), Fm = vec3(0.0);
  const int ND = 64, NS = 24;
  for (int i = 0; i < ND; i++){
    float fy = 1.0 - (float(i) + 0.5)*2.0/float(ND), rr = sqrt(max(1.0 - fy*fy, 0.0)), ph = float(i)*2.39996323;
    vec3 w = vec3(rr*cos(ph), fy, rr*sin(ph));
    float pd = dot(P0, w), tw = -pd + sqrt(max(pd*pd - K0, 0.0));
    float disc = pd*pd - (K0 + (uR - Rt)*(uR + Rt));
    bool ex = pd < 0.0 && disc > 0.0;
    float tEnd = ex ? (-pd - sqrt(disc)) : tw;
    vec3 T = vec3(1.0), Lw = vec3(0.0), Fw = vec3(0.0);
    for (int j = 0; j < NS; j++){
      float a0 = float(j)/float(NS), a1 = float(j + 1)/float(NS);
      float t = tEnd*sq(0.5*(a0 + a1)), dt = tEnd*(a1*a1 - a0*a0);
      vec3 X = P0 + w*t; float Kx = K0 + 2.0*t*pd + t*t, zx = zOfK(Kx);
      vec3 sR = uBetaR*exp(-zx/uHR); float sM = uBetaMs*exp(-zx/uHM);
      vec3 ss = sR + vec3(sM), st = sR + vec3((uBetaMs + uBetaMa)*exp(-zx/uHM));
      vec3 sT = exp(-st*dt), Sint = (ss - ss*sT)/max(st, vec3(1e-9));
      Lw += T*Sint*sunTrans(X, Kx, ls)*(1.0/(4.0*PI));
      Fw += T*Sint; T *= sT;
    }
    if (!ex){ vec3 X = P0 + w*tEnd; Lw += T*uGroundAlb/PI*max(dot(-normalize(X), ls), 0.0)*sunTrans(X, 0.0, ls); }
    L2 += Lw; Fm += Fw;
  }
  L2 /= float(ND); Fm /= float(ND);
  oc = vec4(L2/max(vec3(1.0) - Fm, vec3(1e-3)), 1.0);             // Ψ_ms：用时乘 σ_s 与未遮挡日照
}
```

### 5. 视线积分：两端加密（取自 A，高度改由 K 推）

1. 在视线最高点 t_ap＝−cd 处切成上升段和下降段；与真空核求交，核内跳过（只在开暗幕时乘一项）。上升段归近段 pass，下降段归远段 pass（第四节第 1 条）。
2. 每段再按霾层边界（离壁 5H_M）分成“霾段＋空气段”，霾段分 2/5 的样本。
3. 段内按指数逆 CDF 布样本：t(u)＝−ln(1−u(1−e^(−k)))/k，k＝两端密度相差的 e 倍数；k→0 退化为均匀。上升段向相机加密，下降段向对面内壁加密。
4. 视线不过最高点（朝地、或在上升段就撞到地形或塔）时，样本全部给实际存在的那一段（评审 2 第 9 条）。
5. 每个样本按能量守恒式累加：S＋＝T·(J−J·e^(−σΔt))/σ。逐帧用交错梯度噪声平移，靠时域累积收敛。

```glsl
// air.glsl：近段、远段、探针共用（拼在 common 之后）
uniform vec3 uMoonE0; uniform float uMoonD2;   // 相机处大气外、未被塔挡的月光照度（klux）；相机到月心距离²
float warpU(float u, float k){ return abs(k) < 1e-3 ? u : -log(1.0 - u*(1.0 - exp(-k)))/k; }
vec3 uMoonE_air(vec3 X){ vec3 v = uMoonW - X; return uMoonE0*(uMoonD2/dot(v, v))*towerVis(X, uMoonW, uMoonRho)*veilT(X, uMoonW); }
// 单个空气样本的源项 J（每单位长度、每单位立体角的辐亮度增量）与消光
vec3 airSource(vec3 X, float K, float z, vec3 d, Med m, out vec3 ext){
  ext = m.ext;
  vec3 l; float vis; vec3 E = sunE(X, K, l, vis, Q_ECL_AIR == 1);
  if (uSheath.x > 0.0) E *= sheathT(X, l);                            // 塔缘气层只作用于直射（第 10 条）
  float c = dot(d, l), mus = dot(-normalize(X), l);
  vec3 J = E*(m.sR*phaseR(c) + m.sM*phaseCS(c, uMieG) + m.sY*phaseHG(c, 0.6));
  vec3 Eun = uSunI/dot(uSunW - X, uSunW - X)*veilT(X, uSunW);       // 未遮挡日照（多次散射用）
  vec3 ss = m.sR + m.sM + vec3(m.sY);
  J += ss*msLUT(z, mus)*Eun*msVis(X);                                 // 多次散射：加宽半影
  J += ss*cavityL();                                                  // 空腔：对面世界的光，昼夜都在（评审 2·3）
  if (uMoonAir > 0.5){                                                // 月光（开暗幕时才有存在感）
    vec3 lm = normalize(uMoonW - X); float cm = dot(d, lm);
    J += uMoonE_air(X)*sunTrans(X, K, lm)*(m.sR*phaseR(cm) + m.sM*phaseCS(cm, uMieG));
  }
  return J;
}
// 在 [ta, tb] 上积分；toEnd＝真时样本向 tb 加密；kz＝两端离壁高度差 / 标高
void airMarch(vec3 d, float cd, float ta, float tb, float k, bool toEnd, int n, float jit,
              inout vec3 S, inout vec3 T, inout float TX){
  float len = tb - ta; if (len <= 1e-6 || n <= 0) return;
  k = clamp(k, 0.0, 30.0);
  for (int i = 0; i < 48; i++){
    if (i >= n) break;
    float u0 = float(i)/float(n), u1 = float(i + 1)/float(n), um = (float(i) + jit)/float(n);
    float t0, t1, tm;
    if (!toEnd){ t0 = ta + len*warpU(u0, k); t1 = ta + len*warpU(u1, k); tm = ta + len*warpU(um, k); }
    else { t0 = tb - len*warpU(1.0 - u0, k); t1 = tb - len*warpU(1.0 - u1, k); tm = tb - len*warpU(1.0 - um, k); }
    float dt = abs(t1 - t0), K = Kat(tm, cd), z = zOfK(K);
    vec3 X = uCamW + d*tm;
    Med m = medium(X, z); vec3 ext; vec3 J = airSource(X, K, z, d, m, ext);
    vec3 sT = exp(-ext*dt);
    S += T*(J - J*sT)/max(ext, vec3(1e-9));
    T *= sT; TX *= exp(-m.extX*dt);
  }
}
// 在积分途中插入一个“事件”（平板云）：rgb＝朝相机的辐亮度，a＝灰透射
void applyEvent(vec4 ev, inout vec3 S, inout vec3 T, inout float TX){ S += T*ev.rgb; T *= ev.a; TX *= ev.a; }
```

`uMoonE0`＝相机处大气外、**未乘塔挡**的月光照度：CPU 按 01 第九节第 2 条的式子算（即 `HY.astro.moonLux` 去掉最后的 `lk.vis`），GPU 在 `uMoonE_air` 里按到月心距离平方缩放，再乘该点看月被塔挡的比例与暗幕；只在开暗幕或高档时打开。`sheathT` 定义在第 10 条，拼接时放在 air.glsl 之前。

### 6. 光源项小结

| 项 | 形式 | 说明 |
|---|---|---|
| 太阳单次散射 | E_sun(X)·[σ_R·P_R＋σ_M·P_CS＋σ_Y·P_HG] | E_sun 含 1/d²、塔影（解析弓形）、弦表透射、暗幕；高档再乘月掩日 |
| 多次散射 | σ_s·Ψ_ms(z, μ_s)·E_un·塔影(加宽 4H_R) | 影边不突断 |
| 空腔光 | σ_s·L_cav，L_cav＝探针行 1 的平均辐亮度 | 夜里近处空气被对面白昼微微照亮；白天也加 |
| 月光 | 同单次散射 | 默认只在开暗幕或高档时计 |

**塔影体积光**不需要阴影贴图：塔是竖直的无限长圆柱，从任一点看是一条方位带，带边是过该点的竖直平面，日面被切掉的弓形面积有闭式解。每个空气样本都算一次，于是晨昏的塔影楔、太阳在塔后时塔缘外侧前向散射出的亮边、对面世界昼夜分界在空气里的体积过渡、黄昏横过天空的“明暗墙”，都自然出现。半影宽约为距离的 0.18 倍（5000 km 外约 900 km），所以近段 1/4 分辨率完全够。

### 7. 对面世界辉光与夜

夜就是塔影。天上大片是正处白昼的对面世界，它的光经“对面大气→真空→本地大气”照下来。渲染器里它由三处体现：远段 pass 画出的对面内壁与对面大气；探针行 1 的“大气之外”辐亮度，作为空气样本的空腔入射；地面、云、远壁的空腔照度 `cavityE`。三者同源，所以“头顶能看清的对面世界”与“夜里的照度”在物理上是同一个量，改大气或云时一起变。

**量级**（A 原型在旧定标 128 klux 下测得，新定标 71.5 klux 下乘约 0.56，正式版须重测）：

| 地点与时刻 | 水平面照度 | 说明 |
|---|---|---|
| 罪域正午，H＝40、V＝200 | 约 9×10⁴ lux（旧）→ 约 5×10⁴（新） | 直射占六成 |
| 罪域子夜，同上 | 约 1.1×10⁴（旧）→ 约 6×10³（新） | 01 的上限（无大气）8.4–9.1×10³ |
| 罪域子夜，真空（大气关） | 约 5.8×10³（旧）→ 约 3×10³（新） | 夜不黑不是大气造成的 |

人眼在这样的夜里适应亮度约 1000–2000 cd/m²，比正午只暗 3 EV 上下，是“明视觉的阴天”。

**三个设定旋钮**（界面上统一标“设定／非物理”，默认全关）：

1. **静滞暗幕** k_veil（/千公里，灰吸收，只存在于真空核）。对面世界的光要穿过整条核（约 1.2 万 km），日光只穿半条，所以它压夜比压昼强十倍以上，是唯一“只压夜、不太压昼”的单参数。A 的量级：0.3 → 子夜约 300 lux（暗阴天）；0.6 → 约 15 lux（航海晨昏），此时正午也降到原来的约 1/15，可打开“昼光补偿”（按日光在核内的平均路径把 Eref 调回）。
2. **罪域酸霾**（吸收性，ω≈0.8）：只在罪域，昼夜一起变暗、变黄灰。
3. **罪域厚云**（第十节第 5 条）：夜里只剩透过云的漫射光。

**不提供**“散射性霾压夜”：空腔是积分球，只散射不吸收的介质只会把光重新分配，压不暗夜（评审 1 第 9 条、评审 2 对 B 的意见）。

### 8. 静滞暗幕在合成里的位置

视线的真空段长度 L_core＝b0−a1（没交到核则 0），合成时对“真空段以远”的一切乘 V＝exp(−k·L_core)；日照、月照、空腔光各自在 `veilT` 里乘自己的那段。探针行 1 天然包含暗幕，所以 `cavityE` 也自动变暗。

### 9. 余息（设定）

入冬前 N 日（默认 45 日，01 第八节：轻域日照降得最快在入冬前 48–54 日）起，轻域上空出现白色细灰：ω＝0.98、g＝0.6、标高 3 km。前锋离塔根的地面距离按日期线性外推：s_front＝s₀＋v·(入冬前天数之差)，默认从 1500 km 推到 7000 km（约 120 km/日），前锋宽 300 km。画面：天地发白、远处更淡、日周光晕变大；近处另有屏幕空间的细白飘尘（中档起）。

### 10. 塔缘气层（设定，默认关）

用来给“落日红光”一个物理来源：贴塔面加一层薄空气，标高 H_t（默认 20 km），塔面处消光 n₀。阳光擦过塔缘时穿过的路径长，按 Chapman 近似：

```glsl
// 视线 X→太阳（方向 l）擦过塔面时的额外光学厚度；d⊥＝该线到塔轴的水平最近距离
vec3 sheathT(vec3 X, vec3 l){
  vec2 p = X.xz, q = normalize(l.xz); float tc = -dot(p, q);
  if (tc <= 0.0) return vec3(1.0);
  float dp = abs(p.x*q.y - p.y*q.x) - uA;
  if (dp < 0.0) return vec3(0.0);
  float tau = uSheath.x*sqrt(2.0*PI*uA*uSheath.y)*exp(-dp/uSheath.y)/max(length(l.xz), 1e-3);  // 三维＝二维÷sin（光线与塔轴夹角）
  return exp(-tau*vec3(0.43, 1.0, 2.44));                          // 按瑞利色散
}
```

打开后，每次日面滑进塔缘前会经历黄→橙→红，塔的轮廓镶一道细亮边。是否采纳由作者定（第十九节）。

## 八、地形

### 1. 统一框架

地面是一个以图表坐标 c 为自变量的高度场，两种模式共用同一套层、同一张高度图、同一个求交器：

| | 斜坡模式（0） | 阶地模式（1） |
|---|---|---|
| “高度”沿 | 球面法线 | 重力“上” U（指向塔轴） |
| 基准面 | 内壁球面，倾角＝纬度 | 等 r 圆柱面（真水平）一级级量化 |
| 图表北向 | 地面弧长 −Rψ | 水平距离 −y |
| 离地高度 alt(X) | (R−|X|)＋trench(y)−D(c) | r_g(y, c)−ρ_X＋trench(y) |
| 位移层 | 0–5 全部 | 0、1 进量化前起伏；6、2 作蜿蜒与扶壁相位；3–5 是量化后的细起伏 |

所有量写成**相对相机的差分**（第三节第 3 条），脚下的取值由 pass 2 在 GPU 上自取，所以 alt(0) 恒等于眼高。

**层表**（特征尺度／幅度，幅度再乘域系数：轻域 1.6、平域 0.7、重域 1.0、罪域 1.25、灵薄 0.4）：

| 层 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| 尺度 | 60 km | 6 km | 1.1 km | 200 m | 35 m | 6 m | 15 km |
| 幅度 | 1.2 km | 320 m | 85 m | 18 m | 3.2 m | 0.7 m | 相位 |
| 斜坡 | 位移 | 位移 | 位移 | 位移 | 位移 | 位移 | 不用 |
| 阶地 | 量化前 | 量化前 | 扶壁相位 0.07 级 | 细起伏 | 细起伏 | 细起伏 | 蜿蜒相位 0.35 级 |

各层旋转 1.31·k 弧度后取样，避免方向一致的条纹。像素足迹超过 0.3 倍层尺度时该层淡出（预过滤，远处不闪）；离地间隙远大于余下各层幅度之和时提前停读。第 0 层（60 km、1.2 km）补上评审 2 第 11 条说的“百公里级山体轮廓”；在阶地模式里它把整片阶地抬成一座座台阶山。

### 2. 脚下 pass `foot.frag`（1×1 RGBA32F，每帧）

```glsl
// foot.frag：拼在 common 之后。输出：x 细层 d_f(C)，y 蜿蜒 w(C)，z 扶壁 b(C)，w 量化前起伏 P(C)
layout(location = 0) out vec4 oc;
void main(){
  vec2 dc = vec2(0.0); float amp = uAmpZone;
  float P = amp*(LAY_A[0]*layerTex(0, dc).r + LAY_A[1]*layerTex(1, dc).r);
  float df = 0.0;
  for (int k = 2; k < 6; k++){ if (uGroundMode == 1 && k == 2) continue; df += amp*LAY_A[k]*layerTex(k, dc).r; }
  oc = vec4(df, layerTex(6, dc).r, layerTex(2, dc).r, P);
}
```

斜坡模式下 D(C)＝w＋x。各 pass 的地形函数只用“X 处的值 − 这里的值”，于是 CPU 与 GPU 的高度图不必逐位一致（评审 2 第 6 条的根治）。CPU 只用它的 JS 镜像函数做碰撞和算 `uTerF0`；`uTerF0` 有千分之一级的误差只会让远处崖线整体挪动不到 2 m，不会让人陷进地里。

### 3. 阶地：等高量化＋两层相位扰动

**几何**：“水平”就是离塔轴 r 为常数。踏面是与塔同轴的圆柱面，东西方向本身向上弯（曲率半径＝离轴距离）；崖面近似 y＝常数的竖直面，落在每级踏面朝赤道的一侧。站在踏面上往北（塔根）走，迎面是上一级的崖。

**量化变量**：令 Y(r)＝√(R²−r²)（半径 r 处球面的 |y|）。

```
r_raw = ρ_s(y) − P(c)                      量化前的“原始离轴半径”，P 为第 0、1 层起伏（向上为正）
u     = Y(r_raw)/W − wig·w(c) − jit·b(c)    W＝踏面宽（默认 1.5 km），wig＝0.35，jit＝0.07
k     = ⌊u⌋，f = u − k
Y_q   = W·(k + 1 − S(1 − f))，S(g) = σ·g + (1−σ)·smoothstep(1−c, 1, g)
r_q   = √(R² − Y_q²)；地面 r_g = r_q − d_f(c)（d_f＝第 3–5 层细起伏，向上为正）
```

- **踏面严格水平**：踏面上 S＝0，r_q 只取决于 k。扰动只挪动崖线，不让踏面倾斜。这修正了 A 原型里踏面随蜿蜒起伏 ±0.35·Hc（罪域约 ±300 m）的问题（评审 2 嫁接第 7 条）。
- **崖高自动等于 W·tan(纬度)**：因为 u 在裸球面上就是 |y|/W，相邻两级的半径差＝W·|y|/ρ_s。罪域 0.87 km，涅赫莱恩 1.24 km，伊美忒 2.06 km，圣禁城 2.36 km；赤道附近 tan→0，阶地自然消失；轻域越近塔根崖越高（s＝1300 km 处约 7 km），是“轻域尖峰陡崖”。
- **余坡 σ**（默认 0）：σ＞0 时踏面朝赤道微倾，多出的落差由踏面吸收，崖相应变矮。
- **崖带** c（默认 0.07）：崖面宽 c·W，坡约 85°。
- **去规整**：15 km 级蜿蜒（0.35 级）让崖线弯曲、踏面宽窄不一；1.1 km 级扶壁（0.07 级）让崖面出现扶壁和冲沟；第 0、1 层把整片阶地抬成台阶山。三者都只改相位，踏面仍水平。
- Y＝√(R²−r²) 对两半球对称，塔顶半球自动成镜像，不用分符号。
- `terrainNormal` 用 `altAt` 留下的缓存（gU、gDc），着色前必须先在命中点调一次 `altAt(v, foot, 0)`。

**相机相对写法**（全是小数之差，大数只进分母）：

```
Δρ_s  = −(2y_C·Δy + Δy²)/(ρ_s(y_X) + ρ_s(y_C))
ΔY    = −(Δρ_s − ΔP)·(r_raw,X + r_raw,C)/(Y_raw,X + Y_raw,C)
u_X   = f_C + ΔY/W − wig·Δw − jit·Δb，k′ = ⌊u_X⌋（相对相机所在级），f = u_X − k′
ΔY_q  = W·[k′ + S(1 − f_C) − S(1 − f)]
Δr_q  = −ΔY_q·(Y_q,X + Y_q,C)/(r_q,X + r_q,C)
alt   = eye + Δr_q − (d_f(X) − d_f(C)) − Δρ + Δtrench
```

### 4. 求交器参数（CPU 每帧）

```
uAmpZone  = 相机所在域的起伏系数（用来取上界；远处按该点域系数着色，高度上界取全局最大 1.6）
uLip      = 1.2·Σ_k 3·A_k/L_k·amp + 0.05              细层位移的坡度上界（阶地的崖另作处理）
uClearMax = Σ A_k·amp + 斜坡 0 / 阶地 W·tan(纬度)·1.2 + 0.02     地形高出宏观球面的上界（km）
```

### 5. 两级逐像素求交：`terrain_coarse.frag`（W/4×H/4）与 `terrain.frag`（W×H）

**粗级**用 1/4 分辨率的足迹求交，把“当前足迹下已淡出、但全分辨率仍在的细层”幅度之和从 alt 里减去（包络），求到的是包络面的交点，所以是保守的：全分辨率的视线不会比它更早撞到地。输出 0.97·t_c（再打一折，抵消插值）。

**精级**从 3×3 个相邻粗像素的最小值出发：t₀＝max(0, 0.9·min t_c − 0.01)。9 个都没撞到（天空、远壁、塔），这个像素直接跳过地形，天空像素因此几乎不花钱。之后按 A 的步进走：

- 锥形步进 Δt＝alt／max(L·cosθ−sinθ, 0.3)，θ 为视线相对“上”的仰角；
- 阶地模式下，进崖带之前把步长截在崖带边界（按 du/dt 估），崖带内用 alt/(1+崖坡) 小步走；
- 高过一切可能的地形且相对宏观球面仍在上升时退出（凹面里上升的视线要过了弦中点才往回落，那在几百公里外）；
- 越过地面后割线法细化 5 次；
- **步数用尽按命中处理**（A 原型里贴地掠射曾因此漏成天空色条纹）；
- Q_TER_KM（中档 80 km）以外只读低频（第 0、1、6、2 层与阶地），步长放大，直到 Q_TER_FAR_KM（400 km）。

```glsl
// terrain_lib.glsl：拼在 common 之后（terrain_coarse、terrain、实例、地平线角图共用）
uniform float uW;                                          // 踏面宽 km（崖高＝W·tan 纬度，uHc 为相机处的值）
float gU, gK; vec2 gDc;                                     // 缓存：阶地相位 f、相对级号、图表坐标
float Sg(float g){ return uResid*g + (1.0 - uResid)*sstep(1.0 - uCliffC, 1.0, g); }
float SgD(float g){ float a = 1.0 - uCliffC, x = sat((g - a)/uCliffC); return uResid + (1.0 - uResid)*6.0*x*(1.0 - x)/uCliffC; }
// 崖带截步：f＜c 为崖带（每级朝赤道的一侧）。u 变小＝往赤道走
float cliffStep(float f, float dudt, float a){
  if (f < uCliffC) return a/(1.0 + uHc/(uCliffC*uW));      // 崖带内：按崖坡小步
  float du = dudt < 0.0 ? (f - uCliffC) : (1.0 - f);       // 到下一个崖带起点的相位距离
  return abs(dudt) > 1e-6 ? 0.8*du/abs(dudt) + 1e-4 : INF;
}
float layerFade(int k, float foot){ return 1.0 - sstep(0.3*LAY_L[k], 1.2*LAY_L[k], foot); }
// 细层位移 d_f(X)：返回 x 值，yz 对图表的梯度；clear＝已知的离地间隙（提前停读）
vec3 dispFine(vec2 dc, float foot, float clear){
  vec3 acc = vec3(0.0); float amp = uAmpZone, rest = 0.0;
  int k0 = uGroundMode == 1 ? 3 : 2;
  for (int k = 2; k < 6; k++){
    if (k < k0) continue;
    float fd = layerFade(k, foot); if (fd <= 0.0) break;
    rest = 0.0; for (int j = 5; j > k; j--) rest += LAY_A[j];
    if (clear - acc.x > 2.5*(LAY_A[k] + rest)*amp) break;
    vec4 t = layerTex(k, dc); float A = LAY_A[k]*amp*fd;
    acc += A*vec3(t.r, t.g, t.b);
  }
  return acc;
}
float envMargin(float footC, float footF){                  // 粗级包络：足迹之差造成的淡出幅度
  float m = 0.0;
  for (int k = 2; k < 6; k++) m += LAY_A[k]*uAmpZone*max(layerFade(k, footF) - layerFade(k, footC), 0.0);
  return m + 0.002;
}
// 相对相机的离地高度（km）。lod 0 全部层；1 只低频
float altAt(vec3 v, float foot, int lod){
  vec4 F = texelFetch(uFoot, ivec2(0), 0);
  vec2 dc = chartD(v); gDc = dc;
  float yX = uCamW.y + v.y, amp = uAmpZone;
  float tr = trench(yX) - trench(uCamW.y);
  float P = amp*(LAY_A[0]*layerTex(0, dc).r + LAY_A[1]*layerTex(1, dc).r) - F.w;   // ΔP
  if (uGroundMode == 0){
    float base = uCamAlt - dRho(v) + tr - P;
    float fine = lod == 0 ? dispFine(dc, foot, base).x : 0.0;
    return base - (fine - F.x);
  }
  float w = layerTex(6, dc).r - F.y, b = layerTex(2, dc).r - F.z;
  float rsX = sqrt(max(uR*uR - yX*yX, 0.0));
  float dRs = -(2.0*uCamW.y*v.y + v.y*v.y)/(rsX + uRsC);
  float rawC = uRsC - F.w, rawX = rawC + dRs - P;
  float YC = sqrt(max(uR*uR - rawC*rawC, 1.0)), YX = sqrt(max(uR*uR - rawX*rawX, 1.0));
  float dY = -(dRs - P)*(rawX + rawC)/(YX + YC);           // Y＝√(R²−r²) 两半球对称，不用分符号
  float uu = uTerF0 + dY/uW - uWig*w - uJit*b, kk = floor(uu), f = uu - kk;
  gU = f; gK = kk;
  float dYq = uW*(kk + Sg(1.0 - uTerF0) - Sg(1.0 - f));
  float rqC = uCamRho + uCamAlt + F.x, YqC = sqrt(max(uR*uR - rqC*rqC, 1.0));
  float YqX = YqC + dYq, rqX = sqrt(max(uR*uR - YqX*YqX, 1.0));
  float dRq = -dYq*(YqX + YqC)/(rqX + rqC);
  float base = uCamAlt + dRq - dRxz(v) + tr;
  float fine = lod == 0 ? dispFine(dc, foot, base).x : 0.0;
  return base - (fine - F.x);
}
// 阶地相位沿视线的变化率 du/dt（截步用）
float duDt(vec3 v, vec3 d){
  vec3 X = uCamW + v, gE, gN; chartGrad(X, gE, gN);
  vec4 Lw = layerTex(6, gDc), Lb = layerTex(2, gDc);
  vec3 gradW = Lw.g*gE + Lw.b*gN, gradB = Lb.g*gE + Lb.b*gN;
  vec3 gY = vec3(0.0, sign(X.y), 0.0);                       // 裸球面上 Y＝|y|，∇|y|＝sign(y)·ŷ
  return dot(d, gY/uW - uWig*gradW - uJit*gradB);
}
// 地面法线（解析梯度；只在命中点算一次）
vec3 terrainNormal(vec3 v, float foot){
  vec3 X = uCamW + v, gE, gN; chartGrad(X, gE, gN);
  vec3 dd = dispFine(gDc, foot, 0.0);
  vec3 gD = dd.y*gE + dd.z*gN;                               // ∇d_f
  vec4 L0 = layerTex(0, gDc), L1 = layerTex(1, gDc);
  vec3 gP = uAmpZone*(LAY_A[0]*(L0.g*gE + L0.b*gN) + LAY_A[1]*(L1.g*gE + L1.b*gN));
  vec3 g;
  if (uGroundMode == 0){
    g = -normalize(X) + vec3(0.0, trenchD(X.y), 0.0) - gP - gD;
  } else {
    vec3 rh = vec3(X.x, 0.0, X.z)/length(X.xz);
    float rs = sqrt(max(uR*uR - X.y*X.y, 1.0));
    vec3 gRs = vec3(0.0, -X.y/rs, 0.0);
    float rraw = rs, Yraw = abs(X.y);                         // 分母用近似值即可
    vec3 gYraw = -(rraw/max(Yraw, 1.0))*(gRs - gP);
    vec4 Lw = layerTex(6, gDc), Lb = layerTex(2, gDc);
    vec3 gu = gYraw/uW - uWig*(Lw.g*gE + Lw.b*gN) - uJit*(Lb.g*gE + Lb.b*gN);
    float Yq = abs(X.y), rq = rs;
    vec3 gYq = uW*SgD(1.0 - gU)*gu;
    vec3 gRq = -(Yq/rq)*gYq;
    g = gRq - gD - rh + vec3(0.0, trenchD(X.y), 0.0);
  }
  return normalize(g);
}
```

```glsl
// terrain.frag（W×H，RGBA16F＋深度）：rgb＝表面辐亮度（kn，不含大气），a＝命中距离 km（无为 −1）
uniform sampler2D uTerC; uniform float uPixF;
uniform float uInstNear, uInstFar;                          // 实例相机的 near/far（km）
layout(location = 0) out vec4 oc;
vec3 shadeTerrain(vec3 v, vec3 d, float t, float foot);    // 第 7–8 条
void main(){
  vec3 d = viewRay(gl_FragCoord.xy, uRes, uJitter, 1.0);
  float cd = dot(uCamW, d);
  ivec2 cp = ivec2(gl_FragCoord.xy*0.25); ivec2 cs = textureSize(uTerC, 0);
  float tc = INF; bool anyHit = false;
  for (int j = -1; j <= 1; j++) for (int i = -1; i <= 1; i++){
    float s = texelFetch(uTerC, clamp(cp + ivec2(i, j), ivec2(0), cs - 1), 0).x;
    if (s >= 0.0){ tc = min(tc, s); anyHit = true; }
  }
  if (!anyHit){ oc = vec4(0.0, 0.0, 0.0, -1.0); gl_FragDepth = 1.0; return; }
  float tMax = min(min(Q_TER_FAR_KM, iTower(uCamW, d)), tWallCam(cd));
  float t = max(0.0, 0.9*tc - 0.01), tPrev = t;
  float aPrev = altAt(d*t, max(t*uPixF, 2e-4), t < Q_TER_KM ? 0 : 1);
  if (aPrev < 0.0){ t *= 0.5; tPrev = t; aPrev = altAt(d*t, max(t*uPixF, 2e-4), 0); } // 启发式失手时退半步
  vec3 nUp = uGroundMode == 1 ? vec3(-1.0, 0.0, 0.0) : -normalize(uCamW);
  float sinT = dot(d, nUp), cosT = sqrt(max(1.0 - sinT*sinT, 0.0));
  float kStep = 1.0/max(uLip*cosT - sinT, 0.3), hit = -1.0;
  for (int i = 0; i < Q_TER_F; i++){
    float foot = max(t*uPixF, 2e-4); int lod = t < Q_TER_KM ? 0 : 1;
    float a = altAt(d*t, foot, lod);
    if (a < 0.0){                                             // 割线细化
      float tl = tPrev, th = t, al = aPrev, ah = a;
      for (int j = 0; j < 5; j++){
        float tm = tl + (th - tl)*al/max(al - ah, 1e-9);
        float am = altAt(d*tm, max(tm*uPixF, 2e-4), lod);
        if (am < 0.0){ th = tm; ah = am; } else { tl = tm; al = am; }
      }
      hit = tl; break;
    }
    if (a < 0.3*foot){ hit = t; break; }
    float dt = a*min(kStep, 3.0);
    if (uGroundMode == 1 && lod == 0) dt = min(dt, cliffStep(gU, duDt(d*t, d), a));
    dt = max(dt, 3e-4 + foot*0.8); if (lod == 1) dt *= 2.0;
    tPrev = t; aPrev = a; t += dt;
    if (t > tMax) break;
    if (i == Q_TER_F - 1) hit = t;                            // 步数用尽按命中
  }
  if (hit < 0.0){ oc = vec4(0.0, 0.0, 0.0, -1.0); gl_FragDepth = 1.0; return; }
  vec3 L = shadeTerrain(d*hit, d, hit, max(hit*uPixF, 2e-4));
  oc = vec4(min(L, vec3(6.0e4)), hit);
  float zv = hit*dot(d, uCamFwd);                             // 写出与实例相机同一投影的深度
  gl_FragDepth = zv > uInstFar ? 1.0 : clamp(((uInstFar + uInstNear) - 2.0*uInstFar*uInstNear/zv)/(uInstFar - uInstNear)*0.5 + 0.5, 0.0, 1.0);
}
```

**崖带截步**（`cliffStep`）：每级里 f∈[0, c) 是崖带（朝赤道一侧），f∈[c, 1) 是踏面。视线往赤道走（du/dt＜0）时，离崖带起点还差 f−c；往塔根走时，离上一级崖带起点还差 1−f。步长不超过这段相位距离折成的路程，崖带内按崖坡小步走，所以崖沿和崖脚都不会被跨过去。粗级与精级用同一个函数。

**原型实测的景象**（A，W＝1.5 km）：罪域北望，1.1 km 外就是上一级 0.87 km 高的崖，岩层清楚；圣禁城北望，一级级 2.4 km 的崖台阶在霾里一直叠到天上。往南平视越过阶沿，直接看到约一万公里外塔顶半球的对面世界；俯视则是一级级下降的台阶挤在一条窄带里。

### 6. 高度图生成 `gen_height.frag`（启动时一次，GPU）

1024²、可平铺、每张 32 个特征。R＝4 个八度的周期 Perlin 与山脊噪声混合（A 的配方，按经验系数归一到 [−1, 1]），A＝3 个八度的材质噪声。第二个小 pass 用中心差分写出 GB（对 uv 的偏导），存 RGBA16F。哈希用 PCG3D 整数哈希，JS 里用 `Math.imul` 逐位复刻，JS 镜像只用于碰撞和 `uTerF0`（允许 0.3 m 误差）。

```glsl
// gen_height.frag：输出 RGBA32F（R 高度，A 材质）；随后 gen_height_d.frag 差分出 GB 并转存 RGBA16F
layout(location = 0) out vec4 oc;
uvec3 pcg3(uvec3 v){ v = v*1664525u + 1013904223u; v.x += v.y*v.z; v.y += v.z*v.x; v.z += v.x*v.y;
  v ^= v >> 16u; v.x += v.y*v.z; v.y += v.z*v.x; v.z += v.x*v.y; return v; }
vec2 gradT(ivec2 p, int per, int seed){ p = ((p % per) + per) % per;
  float a = float(pcg3(uvec3(uint(p.x), uint(p.y), uint(seed))).x >> 8u)/16777216.0*6.2831853; return vec2(cos(a), sin(a)); }
float perlinT(vec2 x, int per, int seed){
  ivec2 i = ivec2(floor(x)); vec2 f = x - floor(x), u = f*f*f*(f*(f*6.0 - 15.0) + 10.0);
  float n00 = dot(gradT(i, per, seed), f), n10 = dot(gradT(i + ivec2(1, 0), per, seed), f - vec2(1.0, 0.0));
  float n01 = dot(gradT(i + ivec2(0, 1), per, seed), f - vec2(0.0, 1.0)), n11 = dot(gradT(i + ivec2(1, 1), per, seed), f - vec2(1.0));
  return 1.414*mix(mix(n00, n10, u.x), mix(n01, n11, u.x), u.y);
}
void main(){
  vec2 x = (gl_FragCoord.xy - 0.5)/1024.0;
  float f = 0.0, ridge = 0.0, a = 1.0; int per = 32;
  for (int o = 0; o < 4; o++){ float n = perlinT(x*float(per), per, 11 + o); f += a*n; ridge += a*(1.0 - abs(n)); a *= 0.5; per *= 2; }
  float h = clamp((0.55*f + 0.45*(ridge - 0.9))*1.35, -1.0, 1.0);          // 1.35 为经验归一系数（test/height_range 校核）
  float m = 0.0; a = 1.0; per = 16;
  for (int o = 0; o < 3; o++){ m += a*perlinT(x*float(per), per, 77 + o); a *= 0.5; per *= 2; }
  oc = vec4(h, 0.0, 0.0, clamp(0.5 + 0.5*m, 0.0, 1.0));
}
```

### 7. 阴影

地面上一点的直射＝日照（距离平方、塔影、月掩日、大气、暗幕）× 地形阴影 × 云影。

**地形阴影：地平线角图**（B）。太阳一天只在塔带两侧摆约 ±7°、仰角几乎不动，所以不做级联阴影图，而是围绕相机预算三级“沿日光的净空角”：

| 级 | 半宽 | 纹素 | 主要承担 |
|---|---|---|---|
| 0 | 1 km | 7.8 m | 近处起伏、石块下的小影 |
| 1 | 8 km | 62 m | 崖影、山影 |
| 2 | 64 km | 500 m | 远处台阶山的影 |

每个纹素是一个地面点（抬高 0.5 m），沿该点指向太阳的方向走 32 步（几何分布，从纹素尺寸到 16 km），记下 r＝min(alt(s)/s)（弧度量级的净空角），同时记下烘焙时该点的太阳仰角 g。查用时太阳仰角变了 δ，净空角近似变 δ，所以

```
vis = sat( (r + (el_now − g)) / (2·θ_sun) + 0.5 )        θ_sun＝日面角半径
```

太阳方位变 0.25° 或相机越过 1/4 级宽时重烘焙，每帧至多一级（3600× 快进时三帧轮完）。三级竖拼成 256×768 的 RG16F，用 `WebGLRenderTarget.viewport` 分级写入。

```glsl
// terrain_lib.glsl（续）：由图表偏移求地面点（相对相机），地平线角图、云影图、实例共用
vec3 groundPoint(vec2 dc){
  float dLam = -dc.x/uRref; vec3 v0;
  if (uGroundMode == 1){
    float rc = uCamRho;                                         // 先放在相机的离轴半径上，再沿 ρ̂ 挪到地面
    v0 = vec3(-rc*2.0*sq(sinS(0.5*dLam)), -dc.y, rc*sinS(dLam));
    float a = altAt(v0, 1e-3, 0);
    return v0 + a*vec3(cos(dLam), 0.0, sin(dLam));
  }
  float psiC = atan(uCamRho, -uCamW.y), dPsi = -dc.y/uR, psi = psiC + dPsi, rc = sqrt(uR*uR + uCamK);
  vec3 dF = vec3(2.0*cos(psiC + 0.5*dPsi)*sinS(0.5*dPsi) - sin(psi)*2.0*sq(sinS(0.5*dLam)),
                 2.0*sin(psiC + 0.5*dPsi)*sinS(0.5*dPsi), sin(psi)*sinS(dLam));
  v0 = rc*dF;
  float a = altAt(v0, 1e-3, 0);
  return v0 + a*normalize(uCamW + v0);
}
```

**塔影、日食**：`sunE(..., true)` 里已乘逐点的 `towerVis` 与 `eclipseVis`。月半径（100 km）大于日半径（20 km），月的本影比月本身还大，日食时地上有几百公里的暗斑以约 900 km/h 扫过；01 第十节：罪域一年约四次，两京为 0 次。

**崖脚遮蔽**（解析）：踏面上一点到北面上一级崖脚的水平距离 x、崖高 H，天空可见度＝1−(1−cos atan(H/x))/2，崖脚处 0.5。高档另加地平线角图 0 级上的 8 方向扫描遮蔽。

### 8. 材质与着色 `shadeTerrain`

| 域 | 地表（全部程序生成） |
|---|---|
| 罪域 | 玄武黑（反照 0.034）与锈红 (0.20, 0.068, 0.036) 相间的岩层，按离轴半径分层（真水平的层理）、被噪声扭曲；平处有酸蚀出的黄白硫酸盐结壳；酸蚀麻面降低粗糙度、加 AO；下雨时反照 ×0.55、粗糙度降到 0.35，洼地积黄绿酸水（GGX 粗糙度 0.06），镜面反射取探针天光 |
| 重域（罪域以外） | 暗褐岩、稀疏灌丛 |
| 平域 | 草、土、裸岩按坡度与噪声混合；踏面上有顺阶走的田块条纹 |
| 轻域 | 白垩、灰白岩，余息落下的细灰，霜；圣禁城一带干冷苍白石面 |
| 灵薄带 | 灰烬色，夹黑色玻璃质斑块 |

```glsl
// shade_terrain.glsl：拼在 terrain_lib 之后
uniform float uStrataC;                                       // fract(ρ_C/0.045)，CPU 算，层理才不随行走滑动
struct Surf { vec3 alb; float rough; float wet; };
Surf terrainSurf(vec3 v, vec3 n, float nz, vec4 zw, float limbo){
  vec3 X = uCamW + v, upG = -vec3(X.x, 0.0, X.z)/length(X.xz);
  float flatW = sat((dot(n, upG) - 0.55)/0.4);
  float strata = fract(uStrataC + dRxz(v)/0.045 + nz*1.7);
  float band = (sstep(0.3, 0.5, strata) - sstep(0.7, 0.95, strata))*sstep(0.2, 0.6, nz);
  vec3 basalt = vec3(0.034, 0.030, 0.030), rust = vec3(0.20, 0.068, 0.036), crust = vec3(0.40, 0.36, 0.21);
  vec3 rui = mix(mix(basalt, rust, band*0.85), mix(rust*0.8, basalt, sstep(0.4, 0.7, nz)), flatW);
  rui = mix(rui, crust, flatW*sstep(0.78, 0.92, nz)*0.8);
  vec3 heavy = mix(mix(vec3(0.085, 0.07, 0.058), vec3(0.13, 0.09, 0.06), band), vec3(0.06, 0.07, 0.035), flatW*0.6);
  vec3 grass = mix(vec3(0.055, 0.085, 0.03), vec3(0.11, 0.10, 0.045), sstep(0.3, 0.8, nz));
  vec3 plain = mix(mix(vec3(0.19, 0.18, 0.165), vec3(0.15, 0.12, 0.08), band), grass, flatW);
  vec3 light = mix(vec3(0.42, 0.41, 0.40), vec3(0.62, 0.62, 0.64), flatW*sstep(0.3, 0.7, nz));
  vec3 lim = mix(vec3(0.23, 0.23, 0.24), vec3(0.03, 0.03, 0.035), sstep(0.7, 0.8, nz));
  vec3 alb = mix(mix(light*zw.x + plain*zw.y + heavy*zw.z, rui, zw.w), lim, limbo);
  float wet = uWet*zw.w, puddle = wet*flatW*sstep(0.15, 0.05, nz);
  Surf s; s.alb = alb*mix(1.0, 0.55, wet*0.8);
  s.rough = mix(mix(0.9, 0.35, wet*0.7), 0.06, puddle); s.wet = max(wet*0.5, puddle);
  return s;
}
vec3 shadeTerrain(vec3 v, vec3 d, float t, float foot){
  altAt(v, foot, 0);                                           // 置缓存 gU、gDc
  vec3 X = uCamW + v, n = terrainNormal(v, foot);
  float K = Kat(t, dot(uCamW, d));
  vec2 dc = gDc; float nz = layerTex(3, dc).a;
  Surf s = terrainSurf(v, n, nz, zoneW(X), limboW(X));
  vec3 l; float vis; vec3 E = sunE(X, K, l, vis, true);
  vec3 col = vec3(0.0); float nl = dot(n, l);
  if (vis > 0.0 && nl > 0.0){
    E *= horizonVis(dc, X, l)*cloudShadowT(dc);
    vec3 h = normalize(l - d); float a2 = pow(s.rough, 4.0), nh = max(dot(n, h), 0.0);
    float D = a2/(PI*sq(nh*nh*(a2 - 1.0) + 1.0)), F = 0.02 + 0.98*pow(1.0 - max(dot(h, -d), 0.0), 5.0);
    col += E*(s.alb/PI*nl + s.wet*D*F*0.25/max(max(dot(n, -d), 0.05), 1e-3));
  }
  float ao = 1.0;                                              // 崖脚遮蔽
  if (uGroundMode == 1){
    vec3 upG = -vec3(X.x, 0.0, X.z)/length(X.xz);
    float H = uW*abs(X.y)/max(length(X.xz), 1.0), x = (1.0 - gU)*uW;   // 到北面崖脚的水平距离
    ao = 1.0 - (1.0 - cos(atan(H, max(x, 1e-4))))*0.5*sat((dot(n, upG) - 0.8)/0.2);
  }
  vec3 refl = reflect(d, n);
  col += s.alb/PI*shIrr(n, 0)*ao + s.wet*0.04*shIrr(refl, 0)/PI;   // 天光（含空腔）＋湿面镜面天光
  return col;
}
```

### 9. 远壁（地形求交范围以外）

```glsl
    float wt = W*max(dot(-d, upG), 0.0), wr = H*max(dot(-d, nR), 0.0);

    float shadowFrac = sat(H*max(dot(l, -nR), 0.0)/(W*max(tread, 1e-3)));   // 评审 2·5

  if (uCloudOn > 0.5){                                         // 云影：沿日光挪到云层中高度
    float zc = 0.5*(uCloudBase + uCloudTop);

  float abyss = 1.0 - sstep(uAbyssHalf*0.6, uAbyssHalf, abs(X.y));
```

### 10. 世界底图与舆图接口（评审 1 第 10 条）

## 十、云

### 1. 一张天气图驱动三种尺度

近处体积云（0–40 km）、中景 2.5D 平板（40–1500 km）、对面世界的二维云层，以及地面云影，全部取同一张 `tWeather`（1024×512，等面积 (φ, y)），所以本地云层伸到远方时与对面世界的云自然衔接。

**这个世界特有的环流**：赤道 1.4 g 意味着自转一周约 71 分钟，科氏参数约为地球的 20 倍。大气环流应当是多条窄急流组成的带状结构，像木星。站在地上看，云街沿东西拉长，相邻纬带的云朝相反方向漂（A）。

| 通道 | 含义 | 来源 |
|---|---|---|
| r | 成云势（0–1） | 纬带（sin(9·n_y) 调制）＋域扭曲 fbm（东西拉长 2.6 倍）＋按纬带分布的气旋涡（对数螺线臂）＋锋面带 |
| g | 类型（0 层云 … 1 积云） | 低频噪声；轻域偏层云、平域夏季偏积云 |
| b | 厚度系数 | 0.6–1.4 |
| a | 降水势 | 成云势高且偏层云处 |

烘焙在启动时与每模拟小时做一次（GPU，约 2 ms）；查用时再叠两样随时间变的东西，不必重烘：

- 差速旋转：经度偏移 uJetPhase·sin(9·n_y)，uJetPhase 随模拟时间线性增长（默认每模拟小时 0.02 rad），相邻纬带反向；
- 覆盖度滑杆与罪域阴云：查用时把成云势映成覆盖度，罪域一圈（半径 900 km，强度 0–1 可调）覆盖度抬到 1，再用 Worley 噪声留出偶尔的云缝（对应“夜里偶有月光”）。

```glsl
    cov = max(cov, rw*(1.0 - 0.6*gap)); w.g = mix(w.g, 0.0, rw); w.a = max(w.a, rw*0.8);
  }
  return vec4(cov, w.g, w.b, w.a);

// Schneider 式密度：Perlin-Worley 形状 × 高度剖面 − (1−覆盖)；40 km 内再用 Worley 细节侵蚀
float cloudDens(vec3 X, float z, vec4 wx, int lod){
  float zb = cloudBaseAt(X), zt = cloudTopAt(X), hn = (z - zb)/(zt - zb), cov = wx.r;
  if (hn <= 0.0 || hn >= 1.0 || cov <= 0.01) return 0.0;
  float prof = sstep(0.0, 0.07 + 0.1*wx.g, hn)*(1.0 - sstep(mix(0.3, 0.6, wx.g) + 0.35*cov, 1.0, hn));
  vec3 P = uCM2W*X;
  vec4 s = texture(uNoise3, P/24.0 + uWind*0.02);
  float wfbm = s.g*0.625 + s.b*0.25 + s.a*0.125;
  float shape = sat((s.r - (1.0 - wfbm)*0.45)/0.55 + 0.1);
  float dens = sat((shape*prof - (1.0 - cov))/max(cov, 0.05))*wx.b;
  if (lod == 0 && dens > 0.0){
    vec4 dn = texture(uNoise3D, P/3.2 + uWind*0.08);
    dens = sat(dens - (1.0 - (dn.g*0.625 + dn.b*0.25 + dn.a*0.125))*0.32*(1.0 - dens));
  }
  return dens;
}
// 云内一点的源项（单位：每单位消光的辐亮度）
vec3 cloudSource(vec3 X, float K, float z, float sig, vec3 d){
  float zb = cloudBaseAt(X), hn = sat((z - zb)/(cloudTopAt(X) - zb));
  vec3 l; float vis; vec3 E = sunE(X, K, l, vis, false);
  float c = dot(d, l), tauL = 0.0;
  if (vis > 0.0){
    float s = 0.15;
    for (int j = 0; j < Q_CLOUD_L; j++){ vec3 Y = X + l*s; tauL += cloudDens(Y, zOfK(Kof(Y)), weatherAt(Y), 1)*uCloudSigma*s*0.7; s *= 3.3; }
    tauL += -log(max(cloudShadowT(chartD(X - uCamW)), 1e-4))*(1.0 - hn);   // 云影图给其余部分
  }
  float ms = 0.0, a = 1.0, b = 1.0, g = 1.0;                      // Wrenninge 三阶多次散射（双 HG）
  for (int o = 0; o < 3; o++){ ms += a*exp(-tauL*b)*mix(phaseHG(c, 0.8*g), phaseHG(c, -0.25*g), 0.25); a *= 0.55; b *= 0.45; g *= 0.5; }
  vec3 nIn = -normalize(X);
  float mu = max(dot(l, nIn), 0.05), tauUp = tauL*mu, tauBelow = sig*max(z - zb, 0.0)*0.6;
  float diff = (2.0 + 0.15*tauBelow)/(2.0 + 0.15*(tauUp + tauBelow))*(1.0 - exp(-tauUp));   // 双流：厚云深处的漫射场
  vec3 amb = mix(shIrr(-nIn, 0), shIrr(nIn, 0), hn)*(0.5/PI);    // 云底多吃地面反光，云顶多吃天光（含空腔）
  return E*(ms + diff*mu/PI) + amb;
}
// 双流平板：光学厚度 τ 的云层，返回 rgb＝朝观察者的辐亮度，a＝透射（灰）
vec4 slabCloud(vec3 X, vec3 d, float tau){
  if (tau < 0.01) return vec4(0.0, 0.0, 0.0, 1.0);
  vec3 nIn = -normalize(X);
  vec3 l; float vis; vec3 E = sunE(X, Kof(X), l, vis, false);
  float mu = max(dot(l, nIn), 0.0), xi = 0.15;
  float R = xi*tau/(2.0 + xi*tau), Td = 2.0/(2.0 + xi*tau);
  vec3 Etop = E*mu + cavityE(X);                                   // 云顶受照：直射＋空腔
  float below = sat(dot(d, nIn)*4.0 + 0.5);                        // 视线从下往上＝看云底
  vec3 L = mix(R, Td, below)*Etop/PI;
  return vec4(L, exp(-tau));
}
```

### 2. 近处体积云（0–Q_CLOUD_KM）

在近段 pass 里与空气一起积分（第十二节第 2 条）。视线与云底壳、云顶壳求交，得到一段 [c0, c1]，截到 min(c1, Q_CLOUD_KM, 近段终点)。步数 Q_CLOUD_N 均匀分布，加逐帧抖动。每步：密度 → σ＝dens·uCloudSigma（默认 22/km × 密度）→ 源项 `cloudSource` → 与空气同一个透射累乘。T＜0.01 提前退出。

### 3. 光照

- 太阳：日照（含逐点塔影、距离平方、大气透射）× 云自遮挡（Q_CLOUD_L 个朝日短样本＋云影图给出的其余光学厚度）× Wrenninge 三阶多次散射近似（双 HG，g＝0.8 与 −0.25）。
- 厚云深处的漫射场用双流解析：上方 τ′、下方 τ_b，L_d ∝ (2＋ξτ_b)／(2＋ξ(τ′＋τ_b))。这样厚层云的云底约为 (1−R)·Eμ/π，而不是一片死黑，“灰白天光”靠的就是这一项。
- 环境：探针行 0 的 SH 取朝球心、朝地面两个方向，按云内高度插值；行 0 已含空腔光。
- 夜里太阳项为 0，云只被对面白昼照亮，呈均匀的暗灰。黄昏时塔影的半影边以几百公里宽的软边扫过云盖。

### 5. 罪域厚云盖（B）

罪域终年雨层云：覆盖约 1，云底 uRuiBase 默认 1.2 km，云顶 6 km，光学厚度 uRuiTau 默认 60（低频噪声调制 0.6–1.4 倍）。这种云厚而均匀，体积步进既慢又看不出结构，所以：

- 只对云底 0.6 km 真步进（8 步），得到起伏的乳状云底；
- 上面整体按双流平板（`slabCloud`）作为一个“事件”插进积分；
- 云下加雨雾消光 uRainBeta（0.03/km，罪域能见度约 60 km），地面一律湿；
- 中档起加屏幕空间雨丝（后期，按 uWind 斜落，亮度取当地天光）。

ξ＝0.15、τ＝60 时云底亮度约为云顶受照的 18%/π：罪域正午云下水平面照度约 8–10 klux，天空是一块块浅灰深灰（τ 的起伏）。夜里云顶只受空腔光，云下约为对面辉光的 18%。云缝处 τ 小，能露出塔带、太阳或月亮。

### 6. 中景 2.5D 平板（40–1500 km）

东西向贴地的视线要在云层里穿行上千公里，体积步进管不到（评审 2 第 10 条）。近段 pass 里，视线在 [Q_CLOUD_KM, min(1500, 近段终点)] 内与云壳的交段，取 4 个点读天气图，σ_slab＝覆盖×uCloudSigma×0.3×厚度系数，积出 τ，再用 `slabCloud` 给出辐亮度与透射，作为一个事件插在交段中点。地平线上方因此是一条连续的白亮云带，往上过渡到对面世界的云。

### 7. 对面世界的云

远段 pass 里，视线在对面一侧穿过云壳时（下降段末尾），取一个样本读天气图，τ＝覆盖×τ_typ（层云 20、积云 10）×厚度系数，用 `slabCloud` 作为事件插在对面大气与对面内壁之间；对面内壁的云影在 `shadeWall` 里另算。从一万公里外看过去，就是对面世界的天气图：成片的阴云、雨带、急流云街和气旋涡。

### 8. 与正文

- 罪域“白天只有灰白天光”：厚云下天空均匀灰白，太阳的位置只剩一团较亮的晕。原型 A 在暖黄日光加褐色地面反照下得到偏褐的灰；要更“灰白”，用默认的色适应（第十四节）把日色拉回七成，或调高云的反照（ξ 调小）。
- ch1“天上一条笔直黑带把灰白的天劈成两半”：厚云下塔完全看不见；即使薄云（σ≈1.5/km）受日光照亮，云自身的散射也把塔的对比度压到 5% 以下（C 实测）。这个画面要成立，那一天罪域应当是“酸霾或薄雾后的对面世界”（灰白而亮），或在云缝里，或在黄昏与夜里。见第十九节。
- “夜里偶有月光”：云缝里月亮与对面世界的光一起漏下来。

## 十一、日、月与巨塔

### 1. 太阳

- **几何**：半径 20 km 的发光球，合成 pass 逐子样解析求交，视径严格正确（离太阳 3122–8020 km，视径 0.29°–0.73°）。
- **亮度**：L＝I/(πρ_S²)，I＝Eref·Dref²，约 1.9×10⁹ cd/m²，与距离无关；照度按 1/d² 自然成立。
- **临边昏暗**：按波长取 u＝(0.55, 0.70, 0.85)，L(μ)＝L̄·(1−u(1−μ))/(1−u/3)。日面被塔缘切到最后一线时偏暗偏橙。
- **与塔的先后**：逐子样比较“日球交点距离”与“塔交点距离”，近者胜。太阳在塔面前 40 km，白天大部分时间是“亮日衬黑塔”，C 原型只要像素背后有塔就把日面扣掉，这里改正。
- **一日的样子**（01 第五节）：塔后约 9.5–9.9 h → 被东缘一道竖直的直边切出约 42 分 → 贴东缘约 2.3 h → 亮日衬黑塔约 8–8.5 h → 贴西缘 → 西缘切没 42 分。离塔中线最多 6.7°（罪域）到 9.8°（伊美忒）。重力仰角正午最低。罪域正午 37°–90°，影子短而几乎不动，只是变亮变暗。
- **日色**：大气外 (1.104, 0.978, 0.919)；H＝40 时垂直透射（蓝 0.26、绿 0.56、红 0.76），到地面偏金黄，色适应拉回七成（第十四节）。
- **眩光**：日面在 HDR 里被截断，失能眩光在最终 pass 按到眼照度解析叠加（第十四节第 5 条），被塔、地形、云遮住的部分正确减弱。

### 2. 月亮

- **几何**：`HY.astro.moonPos`，半径 100 km。月离内壁最近 1866 km，视径 1.1°–5.9°（近月最大：罪域 4.9°、伊美忒 5.6°）。月改走与太阳对称的螺旋后，冬天塔根半球的月高而大、只亮五到八成，夏天低而小、近满（01 第一节第 7 条），这些全由几何自动给出。
- **相位**：不贴图。月面每个像素算到太阳的方向；亮的一侧自然朝太阳在天上的方向。
- **逐点塔影**：月面每一点各算自己的 `towerVis`，所以入影、出影是一道**直的**影边扫过月面（灰月约 20 小时）；本影、半影都有。
- **反射**：Lommel–Seeliger 与朗伯各半（满月不暗边、弦月有体感）。归一使盘面积分的几何反照率等于 `P.pMoon`（0.6）：L‑S 部分的几何反照率等于其系数，朗伯部分是系数的 2/3，所以 uMoonAlb＝pMoon/(0.5＋0.5·2/3)/⟨月海调制均值⟩≈0.72/⟨·⟩。相位曲线与 01 的朗伯式略有不同，test/moon_flux 要求 α＜100° 时与 `HY.astro.moonLux` 相差＜15%。
- **月海与环形山**：三维噪声在月面本体系里生成；本体系潮汐锁定，一面始终朝塔轴。
- **世界照**：探针行 2（从月亮看出去的空腔）投成 SH，给月面每个法向的照度。
- **黑月**：日照为 0，只剩世界照。01 第九节：罪域庆典夜 22 时黑月面约 635 cd/m²，背后对岸约 3500 cd/m²，约 18%，是一枚深灰黑盘，挡住背后的辉光（test/black_moon 断言 10%–30%）。黑月正好在塔正面前方时与塔融为一体，`跳到黑月夜` 优先挑 `HY.astro.blackMoonHigh` 为真的时刻（背后是被照亮的内壁）。
- **灰月与“一线”**：月心入影前后约 10 小时，月面亮部被一道直线一点点吃掉。

```glsl
// moon.glsl：拼在 common 之后
uniform float uTowerAlb;                                         // 塔的反照率（默认 0）
vec3 shadeMoon(vec3 Q, vec3 d){
  vec3 n = normalize(Q - uMoonW), nb = transpose(uMoonBasis)*n;
  float mare = texture(uNoise3, nb*0.33 + 0.5).r, crater = texture(uNoise3, nb*1.4 + 0.2).g;
  float A = uMoonAlb*mix(1.18, 0.62, sstep(0.42, 0.6, mare))*(0.92 + 0.25*(sstep(0.75, 0.95, crater) - 0.6*sstep(0.92, 1.0, crater)));
  vec3 v = uSunW - Q; float d2 = dot(v, v); vec3 l = v*inversesqrt(d2);
  float vis = towerVis(Q, uSunW, uSunRho);                       // 逐点塔影：黑月、灰月的直影边
  float mu0 = max(dot(n, l), 0.0), mu = max(dot(n, -d), 0.0);
  float brdf = 0.5*mu0 + 0.5*2.0*mu0/(mu0 + mu + 1e-4);          // 朗伯＋Lommel–Seeliger
  return A/PI*(uSunI/d2*vis*veilT(Q, uSunW)*brdf + shIrr(n, 2));
}
vec3 shadeTower(vec3 X){
  if (uTowerAlb <= 0.0) return vec3(0.0);
  vec3 n = normalize(vec3(X.x, 0.0, X.z)); vec3 l; float vis;
  vec3 E = sunE(X + n*0.5, Kof(X), l, vis, false);
  return uTowerAlb/PI*(E*max(dot(n, l), 0.0) + cavityE(X));
}
vec3 sunDisk(float mu){ vec3 u = vec3(0.55, 0.70, 0.85); return uSunI/(PI*uSunRho*uSunRho)*(1.0 - u*(1.0 - mu))/(1.0 - u/3.0); }
```

`uTowerAlb` 声明在 moon.glsl 里（默认 0，“吸光”；滑杆 0–0.04 试看圆柱的体感）。

### 3. 巨塔的样子

塔是吸光黑体，它“看起来”的样子几乎全由前面那段空气决定。A 原型在罪域北天仰角 70° 处实测（旧定标，比值不受定标影响）：

| 时刻、大气 | 塔带（cd/m²） | 旁边天空 | 塔带暗多少 |
|---|---|---|---|
| 正午，H＝40 | 1.8×10⁴ | 1.9–2.25×10⁴ | 1.2 倍，几乎被大气吞没 |
| 正午，H＝8 | 3900 | 6200–13400 | 1.6–3.4 倍，蓝灰带 |
| 夜里，H＝40 | 780 | 7300–10000 | 10–13 倍 |
| 夜里，H＝8 | 190 | 1.1–2.3×10⁴ | 60–120 倍，纯黑 |

所以“一条笔直的黑带把发亮的天劈成两半”是黄昏与夜里的景象，也是薄大气或云缝里的景象。上午、下午塔带一侧对着对面的白昼，单边清楚。

**各地的塔**（01 第十三节，渲染直接画出，界面说明里列出）：

| 地点 | 头顶塔宽 | 塔根端仰角（北） | 塔顶端仰角（南） |
|---|---|---|---|
| 圣禁城 | 20.3° | 71.1° | 13.5° |
| 伊美忒 | 18.5° | 69.3° | 15.3° |
| 涅赫莱恩 | 14.0° | 62.1° | 22.5° |
| 罪域 | 12.5° | 57.3° | 27.3° |

塔不是从地平线到地平线：两头插进极区内壁，而内壁在凹面里是“抬到天上”的，四周是白色的轻域极冠，各域分界一圈圈套在塔端四周。塔根那端浸在本地的稠密低空里，罪域看去单程透射约 0.27，反而比头顶一段模糊；塔顶那端插进对面内壁的大气里（远段 pass 积分到塔面为止）。伊美忒的“立在天边”与“遮住半边天”按朝向都成立：向南看是一根立在低空的黑柱，抬头看是一条 18.5° 宽、横过天顶的穹带。

### 4. 地平线

- 凹面：沿球面切面仰角 α 看出去，看到的地面在 2R·sin α 之外，大地从脚下一路“翘”上去。
- 斜坡模式：切面本身相对重力水平倾斜（倾角＝纬度），罪域北高南低倾 30°。
- 阶地模式：近处是平的，远处按 30° 的总坡度一级级翘起。北面的“地平线”是一堵往天上去的台阶墙，东西两侧是缓缓上翘的圆柱面。
- 东西向贴地的掠射线在大气里走几百到上千公里，地平线上方 0–10° 是一条白亮雾带（中景平板云也在这里），雾带之上对面的大地重新显出来，一路向上弯进天空：这就是 ch1 写的“地平线向上弯起”。
- 不画星。内壁上看不到星，天空的尽头永远是对面的内壁。

### 5. 日食与月影

`eclipseVis` 给出逐点的日面露出比例：地面着色、云、实例都乘它；高档在空气样本里也乘（`Q_ECL_AIR`），月影在空气里也看得见。HUD 在日食时标出“日食 X%”。01：罪域一年约四次、涅赫莱恩约七次，几乎都是全食，最长约 18 分钟；两京为 0。

## 十二、近段、远段与合成

### 1. 拼接次序

```
场景类 pass = common → shadow（horizonVis、cloudShadowT）→ sheath → air → clouds → moon
             → terrain_lib → shade_terrain → shade_wall → 本 pass
```

各 pass 只拼自己用得到的部分（例如 lut_tau 只要 common）。构建脚本按依赖表拼好，作为字符串内联（第十六节）。

### 2. 近段 pass `near.frag`（中档 W/4×H/4；高档 W/2×H/2）

积分 [0, e]：空气、局地介质（雨、酸霾、余息、深渊雾）、近处体积云、中景平板云，在同一次积分里按先后合成。输出 rgb＝内散射 S（kn），a＝“弦表以外”的灰透射 Tx（云×局地介质）。不单独做时域累积，交给全分辨率 TAA（逐帧平移抖动）。

```glsl
// near.frag（NEAR_SCALE 在 common 里给默认值，高档由 defines 改成 0.5）
uniform sampler2D uSurf;                                         // tSurf：a＝表面距离
layout(location = 0) out vec4 oc;
// 空气段：按两端离壁高度差定加密强度，霾层另分 2/5 样本
void airSeg(vec3 d, float cd, float ta, float tb, int n, float jit, inout vec3 S, inout vec3 T, inout float TX){
  if (tb - ta <= 1e-5 || n <= 0) return;
  float za = zOfK(Kat(ta, cd)), zb = zOfK(Kat(tb, cd));
  float hz = min(5.0*uHM, 0.5*uZtop);
  vec2 sh = tShellCam(cd, hz);                                   // 霾层顶
  float tz = (sh.x > ta && sh.x < tb) ? sh.x : -1.0;
  if (tz > 0.0 && n >= 4){
    int nh = max(2, n*2/5);
    airMarch(d, cd, ta, tz, (hz - za)/uHM, false, nh, jit, S, T, TX);
    airMarch(d, cd, tz, tb, (zb - hz)/uHR, false, n - nh, jit, S, T, TX);
  } else airMarch(d, cd, ta, tb, abs(zb - za)/(za < hz ? uHM : uHR), zb < za, n, jit, S, T, TX);
}
void main(){
  vec2 fc = gl_FragCoord.xy;
  vec3 d = viewRay(fc, uRes, uJitter, NEAR_SCALE);
  float cd = dot(uCamW, d);
  float ts = texelFetch(uSurf, ivec2(fc/NEAR_SCALE), 0).a;
  float tEnd = min(tWallCam(cd), iTower(uCamW, d));
  if (ts > 0.0) tEnd = min(tEnd, ts);
  float e = segments(cd, tEnd).x;
  float jit = ign(fc, uFrame);
  vec3 S = vec3(0.0), T = vec3(1.0); float TX = 1.0;
  if (uAtmoOn < 0.5 && uCloudOn < 0.5){ oc = vec4(0.0, 0.0, 0.0, 1.0); return; }
  // ---- 云壳交段 [c0, c1]（壳取全局最低云底到最高云顶） ----
  float zb = min(uCloudBase, uRuiBase), zt = max(uCloudTop, uRuiTop), c0 = -1.0, c1 = -1.0;
  if (uCloudOn > 0.5){
    vec2 B = tShellCam(cd, zb), Tt = tShellCam(cd, zt);
    if (uCamZ < zb){ if (cd < 0.0 && B.x > 0.0){ c0 = B.x; c1 = Tt.x > 0.0 ? Tt.x : B.y; } }
    else if (uCamZ < zt){ c0 = 0.0; c1 = (cd < 0.0 && Tt.x > 0.0) ? Tt.x : (B.y > 0.0 ? B.y : Q_CLOUD_KM); }
    else if (cd > 0.0 && B.y > 0.0){ c0 = max(Tt.y, 0.0); c1 = B.y; }   // 站在云层之上往下看
  }
  bool hasC = c0 >= 0.0 && c0 < e;
  if (!hasC){ airSeg(d, cd, 0.0, e, Q_NEAR_N, jit, S, T, TX); oc = vec4(min(S, vec3(6.0e4)), TX); return; }
  c1 = min(c1, e);
  // ---- 罪域厚云盖：只步进云底 0.6 km，其余按平板 ----
  vec3 Xc = uCamW + d*c0;
  float ovc = ruiW(Xc)*uRuiOvc*step(0.9, weatherAt(Xc).r);
  float cv1 = min(c1, Q_CLOUD_KM);
  float tSlab0 = cv1, tSlab1 = min(c1, 1500.0); float slabTau = 0.0;
  if (ovc > 0.5){
    vec2 B6 = tShellCam(cd, cloudBaseAt(Xc) + 0.6);
    cv1 = min(cv1, B6.x > c0 ? B6.x : c1);
    tSlab0 = cv1; tSlab1 = c1;
    slabTau = uRuiTau*(0.6 + 0.8*texture(uNoise3, (uCM2W*Xc)/90.0).r)*sat((tSlab1 - tSlab0)/max(c1 - c0, 1e-3));
  } else if (tSlab1 > tSlab0){                                    // 中景 2.5D：4 个样本读天气图
    for (int i = 0; i < 4; i++){ vec3 Y = uCamW + d*mix(tSlab0, tSlab1, (float(i) + 0.5)/4.0); vec4 w = weatherAt(Y);
      slabTau += w.r*uCloudSigma*0.3*w.b*(tSlab1 - tSlab0)/4.0; }
  }
  // ---- [0, c0)：空气 ----
  int nA = Q_NEAR_N/2;
  airSeg(d, cd, 0.0, c0, nA, jit, S, T, TX);
  // ---- [c0, cv1]：体积云＋空气，均匀步进 ----
  float dtc = (cv1 - c0)/float(Q_CLOUD_N);
  for (int i = 0; i < Q_CLOUD_N; i++){
    if (dtc <= 0.0 || max(T.r, max(T.g, T.b)) < 0.01) break;
    float t = c0 + (float(i) + jit)*dtc, K = Kat(t, cd), z = zOfK(K);
    vec3 X = uCamW + d*t;
    Med m = medium(X, z); vec3 ext; vec3 J = airSource(X, K, z, d, m, ext);
    float dens = cloudDens(X, z, weatherAt(X), t < Q_CLOUD_KM ? 0 : 1), sig = dens*uCloudSigma;
    if (sig > 0.0) J += sig*cloudSource(X, K, z, sig, d);
    vec3 e3 = ext + vec3(sig), sT = exp(-e3*dtc);
    S += T*(J - J*sT)/max(e3, vec3(1e-9));
    T *= sT; TX *= exp(-(m.extX + sig)*dtc);
  }
  // ---- 平板事件，然后 (cv1, e]：空气 ----
  if (slabTau > 0.01){
    float tm = 0.5*(tSlab0 + tSlab1);
    airSeg(d, cd, cv1, tm, (Q_NEAR_N - nA)/2, jit, S, T, TX);
    applyEvent(slabCloud(uCamW + d*tm, d, slabTau), S, T, TX);
    airSeg(d, cd, tm, e, Q_NEAR_N - nA - (Q_NEAR_N - nA)/2, jit, S, T, TX);
  } else airSeg(d, cd, cv1, e, Q_NEAR_N - nA, jit, S, T, TX);
  oc = vec4(min(S, vec3(6.0e4)), TX);
}
```

### 3. 远段 pass `far.frag`（W/2×H/2）

积分 [b0, t_end_far]：对面大气（向对面内壁加密）、对面世界的云（平板事件）、对面内壁或浸在对面大气里的塔脚、深渊雾。真空里的塔、日、月不在这里画（合成 pass 逐子样画），所以这里看到的永远是“塔后面的内壁”，被合成 pass 盖住，不会出错。**所有分支都求塔**（修 C 的掠射分支漏塔）。

```glsl
// far.frag
layout(location = 0) out vec4 oc;
void main(){
  vec2 fc = gl_FragCoord.xy;
  vec3 d = viewRay(fc, uRes, uJitter, 0.5);
  float cd = dot(uCamW, d);
  float tW = tWallCam(cd), tT = iTower(uCamW, d);
  vec4 sg = segments(cd, tW); float b0 = sg.y;
  if (-cd <= 0.0 || b0 >= tW){ oc = vec4(0.0, 0.0, 0.0, -1.0); return; }   // 没有远段
  bool towerFar = tT > b0 && tT < tW;                               // 塔脚浸在对面大气里：积到塔面为止
  float tEnd = towerFar ? tT : tW;
  vec3 X = uCamW + d*tEnd;
  // 深渊：壁点在沟里且开了深渊雾 → 视线延长到沟底，下段空气更稠
  float abyssExt = 0.0;
  if (!towerFar && uAbyssDepth > 0.0 && abs(X.y) < uAbyssHalf){
    float mu = max(dot(d, normalize(X)), 0.05);
    abyssExt = trench(X.y)/mu;
  }
  float jit = ign(fc, uFrame + 7);
  vec3 S = vec3(0.0), T = vec3(1.0); float TX = 1.0;
  // 对面云：视线在下降段穿过云壳
  vec2 Ct = tShellCam(cd, uCloudTop), Cb = tShellCam(cd, uCloudBase);
  float tc = (uCloudOn > 0.5 && Ct.y > b0 && Cb.y > Ct.y && Cb.y <= tEnd + 1.0) ? 0.5*(Ct.y + Cb.y) : -1.0;
  // 霾层底（离壁 5H_M）把下降段分成“空气段＋霾段”
  float hz = min(5.0*uHM, 0.5*uZtop); vec2 sh = tShellCam(cd, hz);
  float z2 = (sh.y > b0 && sh.y < tEnd) ? sh.y : b0;
  int nH = (tEnd - z2 > 1e-3) ? max(2, Q_FAR_N*2/5) : 0;
  float zb0 = zOfK(Kat(b0, cd)), zz2 = zOfK(Kat(z2, cd)), ze = zOfK(Kat(tEnd, cd));
  if (tc > 0.0 && tc > z2){                                          // 云在霾段里（常见）
    airMarch(d, cd, b0, z2, (zb0 - zz2)/uHR, true, Q_FAR_N - nH, jit, S, T, TX);
    airMarch(d, cd, z2, tc, (zz2 - zOfK(Kat(tc, cd)))/uHM, true, nH/2, jit, S, T, TX);
    vec3 Y = uCamW + d*tc; vec4 w = weatherAt(Y);
    float tau = w.r*mix(20.0, 10.0, w.g)*w.b;
    applyEvent(slabCloud(Y, d, tau), S, T, TX);
    airMarch(d, cd, tc, tEnd, (zOfK(Kat(tc, cd)) - ze)/uHM, true, nH - nH/2, jit, S, T, TX);
  } else {
    airMarch(d, cd, b0, z2, (zb0 - zz2)/uHR, true, Q_FAR_N - nH, jit, S, T, TX);
    airMarch(d, cd, z2, tEnd, (zz2 - ze)/uHM, true, nH, jit, S, T, TX);
  }
  if (abyssExt > 0.0) airMarch(d, cd, tEnd, tEnd + abyssExt, 2.0, true, 2, jit, S, T, TX);   // 沟里的雾
  vec3 Lend = towerFar ? shadeTower(X) : shadeWall(X, d);
  oc = vec4(min(S + T*Lend, vec3(6.0e4)), tEnd);
}
```

### 4. 合成 pass `composite.frag`（W×H）

```glsl
// composite.frag
uniform sampler2D uSurf, uNear, uFar, uExpTex;
uniform vec2 uNearRes, uFarRes;
layout(location = 0) out vec4 oc;
// 深度感知上采样：低分辨率纹素的“终点键”取它中心对应的全分辨率表面距离（无表面为 −1）
vec4 upNear(vec2 fc, float key){
  vec2 p = fc*NEAR_SCALE - 0.5; ivec2 i0 = ivec2(floor(p)); vec2 f = p - floor(p);
  vec4 acc = vec4(0.0); float ws = 0.0;
  for (int k = 0; k < 4; k++){
    ivec2 o = ivec2(k & 1, k >> 1), q = clamp(i0 + o, ivec2(0), ivec2(uNearRes) - 1);
    float kq = texelFetch(uSurf, ivec2((vec2(q) + 0.5)/NEAR_SCALE), 0).a;
    float sim = (key < 0.0) == (kq < 0.0) ? exp(-abs(kq - key)/(0.1*abs(key) + 0.05)) : 1e-3;
    float w = mix(1.0 - f.x, f.x, float(o.x))*mix(1.0 - f.y, f.y, float(o.y))*sim + 1e-6;
    acc += w*texelFetch(uNear, q, 0); ws += w;
  }
  return acc/ws;
}
vec3 upFar(vec2 fc, float key){
  vec2 p = fc*0.5 - 0.5; ivec2 i0 = ivec2(floor(p)); vec2 f = p - floor(p);
  vec3 acc = vec3(0.0); float ws = 0.0;
  for (int k = 0; k < 4; k++){
    ivec2 o = ivec2(k & 1, k >> 1), q = clamp(i0 + o, ivec2(0), ivec2(uFarRes) - 1);
    vec4 v = texelFetch(uFar, q, 0);
    float sim = v.a < 0.0 ? 1e-3 : exp(-abs(v.a - key)/(0.02*key + 1.0));
    float w = mix(1.0 - f.x, f.x, float(o.x))*mix(1.0 - f.y, f.y, float(o.y))*sim + 1e-6;
    acc += w*v.rgb; ws += w;
  }
  return acc/ws;
}
void main(){
  vec2 fc = gl_FragCoord.xy;
  vec4 surf = texelFetch(uSurf, ivec2(fc), 0);
  vec3 d = viewRay(fc, uRes, uJitter, 1.0);
  float cd = dot(uCamW, d), al = alphaOf(uCamK, cd);
  float tW = tWallCam(cd), tT = iTower(uCamW, d);
  bool onSurf = surf.a > 0.0;
  float tEnd = onSurf ? surf.a : min(tW, tT);
  vec4 sg = segments(cd, tEnd); float e = sg.x;
  vec4 nv = upNear(fc, onSurf ? surf.a : -1.0);
  vec3 Le;
  if (onSurf) Le = surf.rgb;
  else if (tT <= e + 1e-3) Le = shadeTower(uCamW + d*tT);           // 离塔根很近时，塔在近段里
  else {
    vec3 Lfar = upFar(fc, (tT > sg.y && tT < tW) ? tT : tW);
    vec3 acc = vec3(0.0);
    for (int s = 0; s < 4; s++){                                     // 4 子样：日、月、真空里的塔
      vec2 jo = (vec2(float(s & 1), float(s >> 1)) - 0.5)*0.5;
      vec3 ds = viewRay(fc + jo, uRes, uJitter, 1.0);
      float cds = dot(uCamW, ds), tWs = tWallCam(cds);
      vec4 sgs = segments(cds, tWs);
      float tTs = iTower(uCamW, ds); if (tTs >= sgs.y) tTs = INF;       // 塔面在对面大气里：远段已画
      vec2 hs = iSphere(uCamW - uSunW, ds, uSunRho), hm = iSphere(uCamW - uMoonW, ds, uMoonRho);
      float tS = (hs.x < hs.y && hs.x > 0.0) ? hs.x : INF, tM = (hm.x < hm.y && hm.x > 0.0) ? hm.x : INF;
      float tO = min(tS, min(tM, tTs)), Vo = exp(-uVeilK*max(min(tO, sgs.y) - sgs.x, 0.0));
      if (tO >= INF*0.5) acc += exp(-uVeilK*max(sgs.y - sgs.x, 0.0))*Lfar;
      else if (tO == tS){ float mu = max(dot(normalize(uCamW + ds*tS - uSunW), -ds), 0.0); acc += Vo*sunDisk(mu); }
      else if (tO == tM) acc += Vo*shadeMoon(uCamW + ds*tM, ds);
      else acc += Vo*shadeTower(uCamW + ds*tTs);
    }
    Le = acc*0.25;
  }
  vec3 L = nv.rgb + nv.a*transCam(al, cd, e)*Le;
  float expo = texelFetch(uExpTex, ivec2(0), 0).x;
  oc = vec4(min(L*expo, vec3(6.0e4)), min(onSurf ? surf.a : tEnd, 6.0e4));   // a＝视线距离（TAA 重投影用）
}
```

**要点**：

- 近段积分到 e＝min(近段出口, 表面距离)，所以罪域崖顶插进云底、远山没入雾里时，云和空气在地形前后的次序自然正确（评审 1、3 第 1 条）。
- 日面在合成里与塔、月逐子样比较距离，近者胜（修 C 的错误）。
- 真空里的塔、日、月按 4 子样给覆盖率，配合 TAA 抖动，塔缘没有锯齿。
- 远段终点键用像素自己的解析距离（塔脚或内壁），所以塔缘两侧不会混进错误的远段内散射（B 的暗边问题不会出现）。

## 十三、空腔探针与球谐

空心星体是一个积分球：白昼那半边的反射光照亮整个空腔，包括夜里的地面、黑月和对面的大气。所以要有全局光。做法取 C：每两帧（低档每四帧）一个 32×48 的小探针（三行，各 32×16 等面积经纬），投影成 9×3 的 SH，乒乓。每轮读上一轮的 SH，等于逐帧收敛的空腔互反射；增益约为反照率×两程透射≈0.1–0.2，不会发散。

| 行 | 内容 | 用途 |
|---|---|---|
| 0 | 相机看到的全天（本地空气、本地云层的平板近似、对面世界、塔、月；朝下是地面） | 地形、实例、云的天光；照明色（色适应） |
| 1 | 相机看到的“大气之外”：对面世界、对面大气、月，乘本地空气与本地云层的透射；朝下为 0 | 空气样本的空腔入射 L_cav；积分球腔照度 `cavityE` |
| 2 | 从月心看出去：对面内壁（含它的大气）、塔 | 月面世界照（黑月的灰光） |

行 0、1 计入本地云层（评审 3 第 6 条）：用天气图在相机上空的覆盖与厚度做一个平板事件，罪域阴天时地面天光、空腔入射都相应变暗。

```glsl
// probe.frag：32×48，拼在 common → … → shade_wall 之后
layout(location = 0) out vec4 oc;
vec3 airO(vec3 O, vec3 d, float ta, float tb, int n, inout vec3 T){   // 任意起点的简化空气积分（探针用）
  vec3 S = vec3(0.0); float len = tb - ta; if (len <= 0.0) return S;
  for (int i = 0; i < 8; i++){
    if (i >= n) break;
    float t = ta + len*(float(i) + 0.5)/float(n), dt = len/float(n);
    vec3 X = O + d*t; float K = Kof(X), z = zOfK(K);
    Med m = medium(X, z); vec3 ext; vec3 J = airSource(X, K, z, d, m, ext);
    vec3 sT = exp(-ext*dt); S += T*(J - J*sT)/max(ext, vec3(1e-9)); T *= sT;
  }
  return S;
}
vec3 beyond(vec3 O, vec3 d){                                       // 真空以远：塔、月、对面大气与对面内壁
  vec2 wall = iSphere(O, d, uR); float tW = wall.y;
  vec2 core = iSphere(O, d, uR - uZtop);
  float tT = iTower(O, d);
  vec2 hm = iSphere(O - uMoonW, d, uMoonRho); float tM = (hm.x < hm.y && hm.x > 0.0) ? hm.x : INF;
  float b0 = core.y;
  if (tM < min(tT, b0)) return shadeMoon(O + d*tM, d);
  if (tT < b0) return shadeTower(O + d*tT);
  float tEnd = min(tT, tW); vec3 T = vec3(1.0);
  vec3 S = airO(O, d, max(b0, 0.0), tEnd, 6, T);
  return S + T*(tT < tW ? shadeTower(O + d*tT) : shadeWall(O + d*tW, d));
}
vec4 localSlab(vec3 d){                                            // 相机上空云层的平板近似
  if (uCloudOn < 0.5) return vec4(0.0, 0.0, 0.0, 1.0);
  float cd = dot(uCamW, d); vec2 B = tShellCam(cd, cloudBaseAt(uCamW)), Tt = tShellCam(cd, cloudTopAt(uCamW));
  if (!(cd < 0.0 && B.x > 0.0)) return vec4(0.0, 0.0, 0.0, 1.0);
  float t0 = B.x, t1 = Tt.x > 0.0 ? Tt.x : B.y, tm = 0.5*(t0 + t1);
  vec3 X = uCamW + d*tm; vec4 w = weatherAt(X);
  float tau = w.r*uCloudSigma*0.3*w.b*min(t1 - t0, 200.0);
  if (ruiW(X)*uRuiOvc > 0.5) tau = max(tau, uRuiTau);
  return slabCloud(X, d, tau);
}
void main(){
  ivec2 ij = ivec2(gl_FragCoord.xy); int row = ij.y/16;
  vec2 uv = (vec2(float(ij.x), float(ij.y - row*16)) + 0.5)/vec2(32.0, 16.0);
  float ph = uv.x*2.0*PI, ct = 1.0 - 2.0*uv.y, st = sqrt(max(1.0 - ct*ct, 0.0));
  vec3 d = vec3(st*cos(ph), ct, st*sin(ph)), L;
  if (row == 2) L = beyond(uMoonW, d);
  else {
    float cd = dot(uCamW, d);
    vec3 up = uGroundMode == 1 ? vec3(-1.0, 0.0, 0.0) : -normalize(uCamW);
    if (dot(d, up) < -0.02){                                       // 朝地：地面（行 1 为 0）
      if (row == 1) L = vec3(0.0);
      else { vec3 n = up; vec3 l; float vis; vec3 E = sunE(uCamW, uCamK, l, vis, true);
        vec3 alb = vec3(0.12); L = alb/PI*(E*max(dot(n, l), 0.0)*cloudShadowT(vec2(0.0)) + shIrr(n, 0)); }
    } else {
      vec4 sg = segments(cd, tWallCam(cd)); vec3 T = vec3(1.0);
      vec3 Sn = airO(uCamW, d, 0.0, sg.x, 6, T);
      vec4 cl = localSlab(d);
      vec3 Lb = sg.w > 0.5 ? exp(-uVeilK*(sg.y - sg.x))*beyond(uCamW, d)
                           : shadeWall(uCamW + d*tWallCam(cd), d);  // 掠射弦：整根在大气里
      L = row == 1 ? T*cl.a*Lb : Sn + T*(cl.rgb + cl.a*Lb);
    }
  }
  oc = vec4(min(L, vec3(5000.0)), 1.0);
}
```

## 十四、人眼：时域、曝光、色适应、暗视、眩光、色调

后期类 pass 拼 `post_common.glsl`（精度声明、PI、out）。

### 1. TAA（W×H，乒乓）

- 每帧子像素抖动取 Halton(2,3) 前 16 项，全部场景 pass 用同一个抖动（低分辨率 pass 按比例缩小）。
- 重投影：当前像素的视线距离（tHDR.a）给出相对相机的点，转到上一帧相机（位置与基向量都已转到本帧 CM 系），**扣掉上一帧的抖动**（评审 2 第 8 条），在历史里取样。
- YCoCg 空间 3×3 方差裁剪（1.25σ）。
- 历史权重：α＝max(1/n, α_min)。α_min＝0.1，再按模拟时间步长放大：α_min′＝max(0.1, 1−exp(−Δt_sim/120 s))，快进 ×600、×3600 时历史很快让位，太阳、塔影、云不拖影。
- 拍照模式：相机与时间都静止时 n 递增到 64（高档）或 16（中档），逐帧累积。

```glsl
// taa.frag：拼在 post_common 之后
uniform sampler2D uCur, uHist;
uniform vec3 uPrevPos; uniform mat3 uPrevBasisT;                   // 上一帧相机（本帧 CM 系）
uniform vec3 uCamFwd, uCamRight, uCamUp; uniform float uTanHalfFov;
uniform vec2 uRes, uJitter, uPrevJitter; uniform float uExpoRatio, uBlend;
vec3 toY(vec3 c){ return vec3(0.25*c.r + 0.5*c.g + 0.25*c.b, 0.5*c.r - 0.5*c.b, -0.25*c.r + 0.5*c.g - 0.25*c.b); }
vec3 fromY(vec3 y){ return vec3(y.x + y.y - y.z, y.x + y.z, y.x - y.y - y.z); }
void main(){
  ivec2 ip = ivec2(gl_FragCoord.xy); vec4 c = texelFetch(uCur, ip, 0);
  vec3 m1 = vec3(0.0), m2 = vec3(0.0);
  for (int j = -1; j <= 1; j++) for (int i = -1; i <= 1; i++){
    vec3 s = toY(texelFetch(uCur, clamp(ip + ivec2(i, j), ivec2(0), ivec2(uRes) - 1), 0).rgb); m1 += s; m2 += s*s; }
  m1 /= 9.0; m2 /= 9.0; vec3 sig = sqrt(max(m2 - m1*m1, 0.0));
  vec2 ndc = (2.0*(gl_FragCoord.xy + uJitter) - uRes)/uRes.y;
  vec3 d = normalize(uCamFwd + uTanHalfFov*(ndc.x*uCamRight + ndc.y*uCamUp));
  vec3 q = uPrevBasisT*(d*c.a - uPrevPos);                          // 上一帧相机系（x 右、y 上、z 前）
  vec2 pp = (q.xy/max(q.z*uTanHalfFov, 1e-6))*uRes.y*0.5 + uRes*0.5 - uPrevJitter;   // 扣掉上一帧抖动
  vec2 uvp = pp/uRes;
  bool ok = q.z > 0.0 && all(greaterThan(uvp, vec2(0.0))) && all(lessThan(uvp, vec2(1.0)));
  vec3 h = clamp(toY(texture(uHist, uvp).rgb*uExpoRatio), m1 - 1.25*sig, m1 + 1.25*sig);
  vec3 o = ok ? mix(h, toY(c.rgb), uBlend) : toY(c.rgb);
  fragColor = vec4(max(fromY(o), 0.0), c.a);
}
```

### 2. 测光 `meter.frag`（64×32）

从 TAA 结果取 4 个双线性样本求对数亮度，中心加权（注视点），每格的对数亮度截到“上一帧适应亮度 ±5 EV”，日面不进测光（评审 2 第 7 条）。

### 3. 眼 pass `eye.frag`（1×1 RGBA32F，乒乓）

```
La      = exp(加权对数平均)（cd/m²），夹在 [0.003, 1e5]
适应    : 对数域指数趋近，变亮 τ=0.6 s，变暗 τ=3 s（按真实秒，不随快进）
key     = 0.18·min(1, (La/100)^0.2)          亮于 100 cd/m² 时按中灰；越暗 key 越低，夜仍显得是夜
曝光    = key/La·2^EV补偿；“固定 EV”模式下 = 2^(−EV_lock)/1.2（看绝对明暗，比较昼夜）
照明色  = 日光到眼的水平照度色 + shIrr(U, 0)（探针行 0），取色度
色适应  : Bradford，强度 0.7，τ=6 s（照明色而非灰世界：红岩场景不会被拉成青色）
日眩光  : E_eye = E_sun(C)·塔影·月掩日·弦表透射·云（云影图在相机处）·地形（地平线角图 0 级在相机处）
输出    : x 曝光，y 适应亮度，z 日眩光照度，w 打包的照明色度（另存 3 个 uniform 也可）
```

HUD 的照度读数也出自这里：水平面照度＝日光水平分量＋shIrr(U, 0)·π⁻¹·π。每 0.5 s 异步读回 1×1，显示“此刻 X lux ≈ 地球上的××”：

| 照度 | 对照 |
|---|---|
| ＞5×10⁴ | 晴天正午 |
| 10⁴–5×10⁴ | 阴天白昼、晴天上午 |
| 10³–10⁴ | 阴天、日出后不久 |
| 10²–10³ | 很暗的阴天、日落时 |
| 10–10² | 民用晨昏 |
| 1–10 | 深黄昏 |
| 0.1–1 | 满月 |
| ＜0.1 | 星光 |

### 4. 暗视觉（Jensen 2000）

适应亮度从 3 降到 0.003 cd/m² 时按对数插值过渡到视杆亮度 V＝Y·[1.33(1＋(Y＋Z)/X)−1.68]，偏蓝（0.82, 0.92, 1.15）、去饱和，可选轻微模糊和细颗粒。按纯物理的夜（数千 lux）仍是明视觉，只有开了暗幕、在厚吸收云下或深渊里才触发。

### 5. 眩光

- 眼内散射：5 级金字塔，Jimenez 13 点下采样（第一级 Karis 平均防萤火）、帐篷上采样，权重 0.02–0.04。
- 失能眩光（Stiles–Holladay／CIE）：L_veil＝10·E_eye/θ²（θ 以度计，0.3° 以内截平，40° 以外淡出），在最终 pass 按物理照度解析叠加，不受 fp16 截断。E_eye 已乘塔、月、云、地形的遮挡，所以正午太阳挂在黑塔正面时会在黑带上炸开一团光雾，日面滑进塔缘时光雾随之收拢。
- 不做镜头光晕和鬼影：人眼没有这些。

### 6. 最终 pass `final.frag`（屏幕分辨率）

```glsl
// final.frag：放大 → 眩光 → 色适应 → 暗视 → AgX → sRGB → 抖动
uniform sampler2D uHDR, uBloom, uEye, uEyePrev;
uniform vec2 uOutRes; uniform float uBloomK, uPurkinje, uGlareK;
uniform vec3 uSunDirScr; uniform vec3 uCamFwd, uCamRight, uCamUp; uniform float uTanHalfFov;
uniform mat3 uCAT;                                                  // CPU 由 eye pass 的照明色算出的 Bradford 矩阵（强度 0.7）
vec3 agx(vec3 c){
  const mat3 inM = mat3(0.842479062253094, 0.0423282422610123, 0.0423756549057051, 0.0784335999999992, 0.878468636469772, 0.0784336, 0.0792237451477643, 0.0791661274605434, 0.879142973793104);
  const mat3 outM = mat3(1.19687900512017, -0.0528968517574562, -0.0529716355144438, -0.0980208811401368, 1.15190312990417, -0.0980434501171241, -0.0990297440797205, -0.0989611768448433, 1.15107367264116);
  c = clamp((log2(inM*max(c, vec3(1e-10))) + 12.47393)/16.5, 0.0, 1.0);
  vec3 x2 = c*c, x4 = x2*x2;
  c = 15.5*x4*x2 - 40.14*x4*c + 31.96*x4 - 6.868*x2*c + 0.4298*x2 + 0.1191*c - 0.00232;
  return pow(max(outM*c, 0.0), vec3(2.2));
}
vec3 catmull(sampler2D t, vec2 uv){                                  // Catmull–Rom 五点
  vec2 sz = vec2(textureSize(t, 0)), p = uv*sz - 0.5, f = fract(p), c = floor(p) + 0.5;
  vec2 w0 = f*(-0.5 + f*(1.0 - 0.5*f)), w1 = 1.0 + f*f*(-2.5 + 1.5*f), w2 = f*(0.5 + f*(2.0 - 1.5*f)), w3 = f*f*(-0.5 + 0.5*f);
  vec2 w12 = w1 + w2, o12 = (c + w2/w12)/sz, o0 = (c - 1.0)/sz, o3 = (c + 2.0)/sz;
  vec3 r = texture(t, vec2(o12.x, o0.y)).rgb*w12.x*w0.y + texture(t, vec2(o0.x, o12.y)).rgb*w0.x*w12.y + texture(t, o12).rgb*w12.x*w12.y
         + texture(t, vec2(o3.x, o12.y)).rgb*w3.x*w12.y + texture(t, vec2(o12.x, o3.y)).rgb*w12.x*w3.y;
  return max(r/(w12.x*w0.y + w0.x*w12.y + w12.x*w12.y + w3.x*w12.y + w12.x*w3.y), 0.0);
}
vec3 toSRGB(vec3 c){ return mix(12.92*c, 1.055*pow(c, vec3(1.0/2.4)) - 0.055, step(0.0031308, c)); }
void main(){
  vec2 uv = gl_FragCoord.xy/uOutRes;
  vec4 eN = texelFetch(uEye, ivec2(0), 0), eP = texelFetch(uEyePrev, ivec2(0), 0);
  vec3 c = (catmull(uHDR, uv) + uBloomK*texture(uBloom, uv).rgb)*(eN.x/eP.x);     // HDR 里乘的是旧曝光
  vec2 ndc = (2.0*gl_FragCoord.xy - uOutRes)/uOutRes.y;
  vec3 d = normalize(uCamFwd + uTanHalfFov*(ndc.x*uCamRight + ndc.y*uCamUp));
  float th = max(degrees(2.0*asin(clamp(0.5*length(d - uSunDirScr), 0.0, 1.0))), 0.3);
  c += uGlareK*10.0*eN.z/(th*th)*(1.0 - smoothstep(20.0, 40.0, th))*eN.x*vec3(1.104, 0.978, 0.919);   // 失能眩光：E 以 klux 计时 L 直接是 kn
  c = uCAT*c;                                                        // 照明色适应
  float s = uPurkinje*(1.0 - smoothstep(log(0.003), log(3.0), log(max(eN.y, 1e-6))));
  if (s > 0.0){
    vec3 xyz = mat3(0.4124, 0.2126, 0.0193, 0.3576, 0.7152, 0.1192, 0.1805, 0.0722, 0.9505)*c;
    float V = max(xyz.y*(1.33*(1.0 + (xyz.y + xyz.z)/max(xyz.x, 1e-6)) - 1.68), 0.0);
    c = mix(c, V*vec3(0.82, 0.92, 1.15)*0.75, s*0.85);
  }
  float n = fract(52.9829189*fract(dot(gl_FragCoord.xy, vec2(0.06711056, 0.00583715))));
  fragColor = vec4(toSRGB(agx(c)) + (n - 0.5)/255.0, 1.0);
}
```

默认 AgX（高光走向白而不偏橙，适合 H＝40 下偏金黄的日光和昼夜分界处的暖光）；设置里可切 ACES（Hill 拟合）对照。

## 十六、在 three r128 中的接入

### 1. 渲染器与能力检测

```
renderer = new THREE.WebGLRenderer({ canvas, antialias: false, alpha: false, powerPreference: high-performance })
renderer.autoClear = false；renderer.outputEncoding = THREE.LinearEncoding；renderer.toneMapping = THREE.NoToneMapping
renderer.setPixelRatio(1)，按 devicePixelRatio（中档上限 1.5）手动设尺寸
必须：renderer.capabilities.isWebGL2；EXT_color_buffer_float
可选：OES_texture_float_linear（弦表用 32F）、EXT_disjoint_timer_query_webgl2（逐 pass 计时）、KHR_parallel_shader_compile
生产环境 renderer.debug.checkShaderErrors = false（少一次同步查询）
```

缺 `EXT_color_buffer_float` 时：HDR 链改 RGBA8＋RGBM（M 取 64，预曝光后的范围够用），查找表存对数编码，强制低档，界面提示“画质降级”。连 WebGL2 都没有时显示静态说明页。

### 2. 全屏 pass

- 几何：一个三角形，position＝(−1,−1,0)、(3,−1,0)、(−1,3,0)，`frustumCulled = false`，放在单独的 Scene 里，配一个 OrthographicCamera；每个 pass 只换 `mesh.material`、`renderer.setRenderTarget(rt)`、`renderer.render(scene, cam)`。
- 顶点：`void main(){ gl_Position = vec4(position.xy, 0.0, 1.0); }`（three 已声明 `position`）。
- 材质：`new THREE.ShaderMaterial({ glslVersion: THREE.GLSL3, uniforms: U, defines: Q, vertexShader, fragmentShader, depthTest: false, depthWrite: false })`。r128 在 GLSL3 下不代声明片元输出，每个片元着色器自己写 `layout(location = 0) out vec4 …;`；不能用 `varying`（three 会把它 #define 成 in/out）。
- 所有材质共用同一个 uniform 对象 U（同一批 `{value}` 引用），CPU 每帧只改 value，不重建材质。数组 uniform（`uOrg[7]`、`uHzLvl[3]`）用 THREE.Vector2/Vector4 数组；mat3 用 THREE.Matrix3（注意 `.set()` 按行传参）。
- 名字一律 u 前缀，避开 three 注入的 `cameraPosition`、`viewMatrix`、`projectionMatrix`、`isOrthographic` 等。
- 画质切换：改 defines 后 `material.needsUpdate = true` 重编。

### 3. 渲染目标

| tMS、tSkyLUT | 32²、64×1 | HalfFloat | Linear | Clamp |

### 4. 实例

`InstancedBufferGeometry`＋自定义 ShaderMaterial（GLSL3）。实例相机放在原点（相机相对渲染）：`PerspectiveCamera(fov, aspect, 1e-4, 3)`（km），`up` 设为 U，`lookAt(fwd)`；顶点着色器用 three 注入的 `projectionMatrix`、`viewMatrix`，位置全部是相对相机的 CM 坐标，没有大数。每种实例一个 InstancedMesh，`frustumCulled = false`，实例数按档位固定。

### 5. 一帧的调用顺序（JS 伪代码）


### 6. 编译与启动

- 场景类着色器很大，ANGLE 首次编译要几秒（A 实测 4.7–6.1 s，驱动缓存后约 0.5 s）。启动时只编低档，先出画面；首帧之后在空闲回调里逐个 `renderer.compile()` 中档程序，界面角落显示“正在编译（3/12）”，全部编完再切档。
- three r128 在链接后立即查询程序状态，`KHR_parallel_shader_compile` 发挥不了多少作用；保留检测，留给以后升级 three 时用。
- 三维噪声 64³ 在 JS 里约 1.3 s：分帧生成（每帧 4 个切片），生成完之前云用天气图的平板近似。高度图、天气图、世界底图都在 GPU 上生成，各约几毫秒。
- 时间计时：`EXT_disjoint_timer_query_webgl2` 直接用原生 gl 在每个 `renderer.render` 前后插 query，不影响 three 的状态；结果进 HUD 与 `HY.app.gpuTimes()`。

## 十七、“生活其中的人”：交互与界面

### 1. 眼睛与身体

- 眼高 1.6 m（可调 1.2–2.0）；“上”锁定为 U（垂直指向塔轴），横滚恒 0，所以站在 30° 的坡上人也是直立的，地平线是一圈斜环。
- 竖直视角默认 55°（水平约 90°），设置里 30–100°；“凝视”（滚轮或双指）在默认与 1/2 之间平滑缩放；“望远”（T 键）5°，用来细看塔缘、月相、对面大陆。
- 拖动或鼠标锁定（点击画面进入，Esc 退出）转头；行走时有很轻的头部起伏（步频 1.8 Hz、幅度 1.5 cm，可关）。
- 行走：WASD 1.4 m/s，Shift 跑 4.5 m/s，R 切换骑马 12 m/s；崖沿停步，崖面不能站；斜坡模式下坡度超过 35° 时减速。触屏：左下虚拟摇杆走，右半屏拖动看。

- 默认实时流动：云缓慢漂移，太阳在塔身前缓慢横移。流速 ×1、×60、×600、×3600 与暂停；快进时 TAA 历史与云的时域权重按模拟时间衰减（第十四节第 1 条）。

## 十九、风险、与正文的张力、待作者拍板

渲染器只如实呈现，不偷偷“修”设定。下列各条在界面说明里也要讲清楚。

1. **夜不黑（最大）**。纯物理下塔影里的夜被对面白昼照到数千 lux，像阴天的白天；没有大气也有约 3 klux。头顶是一片发光的“白昼透镜”，被黑塔从中劈开；黑月是透镜里的一枚深灰盘。正文里黑夜、月光、“黑月高悬”这类夜景，需要作者从三条里选（与 01 第十五节第 1 条同一件事）：认下白夜（ch20“王城的夜里从来没有真正黑透过”已有此意）；静滞暗幕（k＝0.3–0.6/千公里，子夜压到约 300–15 lux，代价是季节差变大）；局地厚云或酸霾。月光（≤25 lux）在白夜里只体现为“能看见月面”，不是照明。
2. **白天几乎看不见巨塔**。H＝40 时正午塔带只比旁边暗 1.2 倍。“立在天边”“遮住半边天”“黑带劈开天空”在厚大气的正午不成立，在黄昏、夜里、薄大气或云缝里成立。ch1 那句若写的是罪域白天，要么罪域的“灰白的天”是酸霾或薄雾后的对面世界（光学厚度不超过约 3），要么把标高调小；默认的厚云下塔完全看不见。
3. **没有红色落日**。太阳永远在球心方向 30.7° 以内，日光气路恒短，全天同色。涅赫莱恩“夏日傍晚的落日红光”只有三种来源：日面被塔缘切到最后一线时的临边昏暗（偏橙，渲染器原生支持，01 的“一线橙边”）；可选的塔缘气层（设定，默认关）；当地尘幕或火山灰（需另设）。
4. **罪域阴云下天色偏褐**（暖黄日光加褐色地面反照）。默认的照明色适应拉回七成；要更“灰白”，可调高云反照或把 H 调小。
5. **罪域的太阳一年到头都高**（正午 37°–90°），全天高度几乎不变，影子短而几乎不动，只是变亮变暗；墙上的光斑一天只挪很小一段，方向是自西往东（01 第十四节第 22 条）。
6. **圣禁城“每日午后过影一刻钟”**。塔影就是整个夜，造不出午后的短影；阶地崖面朝南、正对太阳，崖影也落不进城；默认参数下两京日食为 0 次。渲染器不硬造这件事；HUD 会标出任何日食。处理办法见 01 第十四节第 17 条（非光学的静滞现象、改写，或 bing 预设的冬季影期）。
7. **伊美忒“立在天边”与“遮住半边天”**：01 按字面判 ✗；渲染上两说按朝向都看得到（向南是一根立在低空 15° 的黑柱，抬头是一条 18.5° 宽的穹带）。是否写进地名志由作者定。
8. **阶地参数**（待确认）：本稿取“踏面宽 W 全局固定、崖高＝W·tan(纬度)”，于是罪域 0.87 km、圣禁城 2.36 km，越近塔根崖越高（s＝1300 km 处约 7 km），赤道附近阶地消失；崖面朝赤道（往塔根走时迎面是崖）。若要“崖高处处相同、踏面宽随纬度变”，量化变量改成 r/Hc 即可，两种写法都已在第八节第 3 条的框架里。
9. **舆图映射**（待定锚点）：舆图 world 图比例尺自注“只作估算”，与 6670 km 对不上。在作者给出锚点前，对面世界只用程序底图。
10. **近似带来的偏差**：探针只代表相机所在处；积分球腔照度假设壁间照度处处相同（只修正塔的遮挡）；远处云是平板；月面 BRDF 的相位曲线与 01 的朗伯式不完全相同（＜15%）；塔影里空气的空腔项读上一轮的 SH（隔帧延迟）。
11. **精度过渡**：200–400 km 处阶地从几何过渡到像素以下，靠足迹淡出与 TAA 压闪；崖面本质是高度场，不能有悬垂和洞穴；400 km 以外地形只有微面统计。
12. **性能与兼容**：没有在集显上实测；three r128 编译时会卡顿（先低档、后台编中档）；缺 `EXT_color_buffer_float` 的设备走 RGBM 降级；升级 three 到 r137 以后要把 DataTexture3D 改名。
13. **可选设定**（都默认关，都标“设定”）：静滞暗幕、昼光补偿、罪域酸霾、塔缘气层、余息的强度与时段。由作者拍板后再改默认值。
