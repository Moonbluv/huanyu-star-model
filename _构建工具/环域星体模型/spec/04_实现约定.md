## 二、统筹修订落在哪里（优先于规格书）

### 1. 历法：不用“一月…十二月、初一…三十”

- **内部时间 `t` 不变**（01：t＝0 是 10018 年入冬交节，伊美忒子夜）。`HY.astro` 一字未改。
- **界面一律显示**：`第 N 年（庆典年 · 周期第 1 年）· 入冬后第 d 日 · 冬／夏第 n 日 · 月态第 k 夜`。文字只许由 `HY.world.fmtCal(info, form)` 生成；`form` 取 `'full'`（默认）`'year'` `'date'` `'season'` `'moon'` `'chip'`。
- **叫法只改一处**：`HY.world.CAL.names`（“第 {N} 年”“入冬后第 {d} 日”“{s}第 {n} 日”“{m}第 {n} 夜”“庆典年”“周期第 {k} 年”、季名、月态名、分隔符、“待定”）。
- **年号口径**也在这一处：`HY.world.CAL.yearStart`，三选一，默认 `'civil'`。

  | 口径 | “第 N 年”从哪天换号 | D1 | 庆典夜 | 飞升日 | 黑曜日 |
  |---|---|---|---|---|---|
  | `'civil'`（默认） | 旧民用历岁首（入冬后第 61 日） | 10018 | 10018 | 10018 | 10008 |
  | `'winter'` | 入冬交节 | 10017 | 10017 | 10018 | 10007 |
  | `'winterEnd'` | 入冬交节（第 N 年在 N 年的交节结束） | 10018 | 10018（年末最后一夜） | 10019 | 10008 |

  默认取 `'civil'` 是因为它不动任何正典年份；代价是换号落在“入冬后第 61 日”这个旧历遗留的日子上。`'winterEnd'` 同样不动 D1、庆典夜、黑曜日的年份，换号落在交节，但飞升日算下一年。**待作者拍板**。
- **CalInfo**（`fmtCal` 的输入，也就是 `HY.model.now.cal`）：`{ N, cyc, festival, wd, hour, season, seasonDay, moonState, moonNight }`。
- **`HY.calc.civil(t, az, P)`** 改为返回 `{ N, wd, doy, rel, hour, cyc, festival, mo, d, label }`：`wd`＝入冬后第几日（1–360），`doy`＝本年第几日（0–359，年首按口径），`rel`＝相对第 N 年入冬交节的整日数（可负），`cyc`＝庆典周期第几年（1＝庆典年那一轮），`mo`、`d` 只供与 `HY.astro.tOf` 对照、界面不显示。反函数 `HY.calc.tOfCivil(N, doy, hour, az, P)`。
- **正文日期标记**只在 `HY.world.MARKS`，一律写成“相对入冬交节的日数”：每行 `{ id, label, kind, every | year, rel, hour, relFrom, festivalOnly, tbd, note }`。旧草案对照：D1＝入冬前 67 日（八月廿四），D2、D3＝前 66、65 日，黑曜日＝10008 年入冬前 51 日（九月初十），庆典夜＝入冬前 1 日 21 时，余息＝入冬前 `fp.set.yuxiLead` 日。D1–D3、黑曜日标 `tbd`（图上写“待定”）。
- 用法：`HY.world.markT(mark, N, az, P, opt)` 求某标记的 t；`HY.world.markList(N, P, {az, yuxiLead})` 求第 N 年里的全部标记（带 `doy`、`wd`）；`HY.world.yearSpan(N, P, az)` 求第 N 年的 `[t0, t1)`；`HY.world.winterT(N, P)` 求 N 年入冬交节。
- 一年图、日月高度图、日期滑杆的横轴＝第 N 年的 `doy`；刻度文字写“入冬后第 X 日”。“日期…”对话输入“年、入冬后第几日、时、分”。`HY.app.setTime` 接受 `{year, wd, hour}`（另保留 `{year, doy, hour}` 与旧的 `{year, month, day, hour}`，后者只为对照 02、03 的测量表）。
- 新增 `HY.calc.moonNight(O, t, P) → {state, night}`（此刻月态是该月态的第几夜），`HY.model.now.moon.night` 取自它。`HY.calc.blackPeriods` 改返回 `[{from:{wd, rel}, to:{wd, rel}}]`。

### 2. 夜：默认如实画“白夜”

- 新增状态 `fp.set.veil`（布尔，默认关，标“设定”）；`fp.set.veilK` 改作“夜幕强度”（0–1 /千公里，默认 0.3，只在 `veil` 为真时生效）。
- 映射（E 路 `fp/settings.js`）：`uVeilK ＝ veil ? veilK / 1000 : 0`（uniform 单位 /km）。
- 界面：“设定”组里一个开关＋一个滑杆（`HY.ui.PARAMS` 已有示范行）。

### 3. 光度定标与月面反照率进“高级”

- `astro.calib` 默认 `'5772K'`；`astro.o.pMoon` 默认不覆盖（＝0.6）。两行在 `HY.ui.PARAMS` 里标 `advanced: true`（D 路做折叠）。

### 4. 地面默认阶地

- `fp.ground.mode` 默认 `'terrace'`（W 固定，崖高＝W·tan 纬度），可选 `'slope'`（界面叫“顺着球面的斜坡”）。`uGroundMode ＝ mode === 'slope' ? 0 : 1`，UNIFORMS 默认 1。

### 5. 文案

- 界面全中文；文案里的引号用中文引号；说明文字简短、直白。`build.py` 对“直双引号包中文”告警（模板正文与 JS 字符串内容），不阻断。

**写入方唯一**：

- uniform 的写入方：`cam`（`fp/camera.js`）、`cel`（`fp/celestial.js`）、`set`（`fp/settings.js`）、`pass`（`fp/passes.js`：分辨率、抖动、帧号、全部 sampler）、`inst`（`fp/instances.js` 自己的）。写入一律经 `HY.fp.apply(U, vals, 写入方)`，写别人名下的 uniform 在 `--dev` 下抛错。`cam`、`cel`、`set` 三个模块只产出普通数值对象（不碰 THREE），由 `fp/fp.js` 每帧 `apply`。
- 状态的写入方见 03 第三节第 3 条；视图、图表不改别人的状态。`src` 取值：`ui play jump walk ov fp api load reset`。
- 事件：`set`／`patch`／`reset` 以顶层键为事件名，载荷 `{path, value, prev, src}`（`patch` 另带 `paths`）；参数约束被夹时发 `error {part:'params', level:'warn', path, message}`。`HY.bus.on('*', fn)` 收全部事件，`fn(payload, 事件名)`。

**着色器拼接**：`HY.fp.passes.assemble(pass)` 返回“chunks ＋ main”的片元源码（不含 `#version`，three 加）；顶点用 `assembleVert`。defines 用 `definesFor(tier)`，浮点宏写成带小数点的字符串（`'40.0'`）。后期类 pass 只拼 `post_common`（它已声明 `layout(location = 0) out vec4 fragColor;`），场景类自己声明 `oc`。

**HY.glsl 的键**：文件名去扩展名；`.vert` 另加 `_vert`（`inst.vert → inst_vert`，`inst.frag → inst`；`ov_shell.vert → ov_shell_vert`）。`build.py` 与 `test/_load.js` 同一规则，键冲突构建失败。

## 五、测试与构建的约定

- `test/run_all.js` 收录 `test/*.js`，去掉 `_load.js`、`run_all.js` 与浏览器用的 `render_*.js`；每个文件一个独立进程，任何一个以非零退出即整体失败。总预算 60 秒（现在 5.5 秒，`astro_check` 占 5 秒）。
- 测试文件开头 `const HY = require('./_load.js')();`（全部 node 模块）或 `({only: [...]})`／`({upto: 'core/store.js'})`。小断言库：`require('./_load.js').tester(名)` → `{ok, near, eq, throws, section, done}`。
- 别的路尚未完成导致的失败：在自己的报告里记下，不改别人的文件。
- `build.py` 的检查：骨架（无 doctype／html／head／body、恰一个 `<title>环域星体模型</title>`、第一行 `<meta charset="utf-8">`）、外部依赖白名单（three r128 cdnjs、OrbitControls jsdelivr 0.128.0、Google Fonts）、源码里不许有 `fetch(` `XMLHttpRequest` `importScripts` `new Worker(` `import(` `document.write` 与行首 `import`／`export`（JS 注释里写没关系，检查会先去掉注释；字符串里的仍算违规）、内联安全、`src/` 下每个 `.js` 都在 manifest 里、`node` 语法检查、体积。新建 `.js` 文件须先进 `src/manifest.json`（统筹改），否则构建失败。
